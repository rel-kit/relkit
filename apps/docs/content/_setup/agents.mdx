## Pre-setup

Use local Docker Redis for agent checkpoints and live updates. Model execution is a separate
choice: begin with the deterministic model in the [offline agent guide](/guides/ai/build-an-offline-agent).
Docker does not supply a hosted model or an API key.

Use `stateProfile: "default"` in the agent, or omit it to select this default. Redis credentials
come from Docker. The deterministic model needs no environment key. When selecting a hosted model,
declare its required key as `env.secret()` in your existing `defineEnv`, supply it to the backend
process, and follow that model's [native configuration](/docs/modules/ai/agents).
The declaration validates the key; it does not configure the model automatically.

Tools exposed only through MCP do not need checkpoint storage. Workspace files use a separate
[bucket profile](/docs/modules/storage#pre-setup) when selected.
