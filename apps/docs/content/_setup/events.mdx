## Pre-setup

Application events currently use the filesystem provider. It has no Docker recipe; Redis's
cache/realtime adapters do not provide application events. Other configured capabilities
can still use local Docker in this same application.

<Step title="Validate the event and consumer" icon="terminal">

After registering the event and listener, run `bun run check`, `bun run typecheck`, and
`bun run dev`. Follow [Handle order events](/guides/events/react-to-order-events) to publish
an event and verify its consumer. Defining an event alone does not run a listener.
