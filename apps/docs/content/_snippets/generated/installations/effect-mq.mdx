```sh
bun add @relkit/docker@0.7.13 @relkit/effect-mq@0.8.2 @relkit/local@0.7.13 drizzle-orm@1.0.0-rc.5-169397b effect-mq@0.7.0

```

The selected Drizzle version also needs the release's declaration repair. The development-only `create-relkit` package supplies its exact asset; a dependency cannot register Bun patches for its consumer.

```sh
mkdir -p patches
cp node_modules/create-relkit/dist/patches/drizzle-orm.patch patches/drizzle-orm@1.0.0-rc.5-169397b.patch
```

Merge this entry into the application's existing `patchedDependencies`, preserving other patches. Keep the asset in source control:

```json
{
  "patchedDependencies": {
    "drizzle-orm@1.0.0-rc.5-169397b": "patches/drizzle-orm@1.0.0-rc.5-169397b.patch"
  }
}
```

Then apply the registered repair before check/typecheck:

```sh
bun install
```

Keep these owner-specific versions and the lockfile together. Runtime SDKs belong in `dependencies`; build/type tooling belongs in `devDependencies`. Installing an adapter does not supply its optional SDK peers or enable the feature's configuration.
