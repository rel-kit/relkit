## Scaffold a bucket

From the application root, with an existing `assets` service:

```sh
bun run relkit add bucket Uploads --service assets --provider s3 --source docker
```

Creates `src/assets/buckets/uploads.bucket.ts` and configures Docker MinIO/S3. Without provider
flags, scaffolding reuses an eligible default/unique profile or creates a Docker S3 profile.
A bucket profile can belong to only one bucket; an already-owned profile is rejected.

| Selection                               | Command options                               |
| --------------------------------------- | --------------------------------------------- |
| Unused compatible profile               | `--profile uploads`                           |
| Docker MinIO/S3                         | `--provider s3 --source docker`               |
| Connected S3                            | `--provider s3 --source connected`            |
| S3 on an existing AWS/Pulumi deployment | `--provider s3 --source aws`                  |
| Connected Cloudflare R2                 | `--provider cloudflare-r2 --source connected` |

Do not combine `--profile` with `--provider` or `--source`. Cloudflare R2 supports only
`connected`. AWS requires an existing AWS/Pulumi deployment and is not provisioned by this command.
Set connected-profile environment values yourself; the CLI never asks for credentials.
See [Docker startup after adding a resource](/docs/start/add-artifacts#start-local-resources).
The bucket remains internal; declare it as a function dependency to use it.

## Define the bucket

Use `defineBucket` in your app's domain directory. Create `src/assets/buckets/assets.bucket.ts`:

<include cwd lang="ts" meta='title="src/assets/buckets/assets.bucket.ts"'>
  ../../examples/commerce/src/assets/buckets/assets.bucket.ts
</include>

- `id` is the bucket's stable, unique name. Keep it unchanged when moving or renaming the file.
- `visibility` is required. Start with `"private"` for user uploads.
- `maxObjectBytes` sets the maximum size of one file: 5 MB here.
- `allowedContentTypes` lists accepted media types. `image/*` allows image types; `application/json` allows JSON files.
- `profile` selects a physical bucket configuration in `relkit.config.ts`. This example uses `"assets"`.

Size and content-type limits are optional. For HTTP uploads, also validate incoming files with `z.file()` as shown in [Upload files](/docs/storage/upload).

## Check your bucket

Make sure the `assets` bucket profile exists in `relkit.config.ts`; the [tutorial's configuration step](/docs/storage/first-upload#configure-storage) shows how to add it.

Then, from your app's root, run:

```sh
bun run check
```

Next, [give a function access to the bucket](/docs/storage/upload). For cloud storage, [configure an integration](/docs/integrations).
