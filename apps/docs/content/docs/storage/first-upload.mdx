Create the four files below. If your app already has an Assets service or an uploads route, merge these members into it. Run commands from your app's root.

## Upload two images

Check and start the app:

```sh
bun run check
```

```sh
RELKIT_ENV=test bun run dev
```

`RELKIT_ENV=test` uses local storage without cloud credentials. Keep the app running and open a second terminal in the app's root.

Place two small PNG images named `cover.png` and `detail.png` there. Keep their combined size below 1 MB for this request, then send:

```sh
curl -i http://localhost:3000/uploads \
  -F 'label=book-photos' \
  -F 'primary=@cover.png;type=image/png' \
  -F 'attachments=@detail.png;type=image/png'
```

Use your app's configured port if it differs from `3000`. Expect HTTP 200:

```json
{ "label": "book-photos", "files": ["cover.png", "detail.png"] }
```

## Check the stored files

Open your app's Inspector, normally at `http://localhost:3210`. Select **Buckets**, open `assets.objects`, and look for `cover.png` and `detail.png`. Click **Preview** beside either key to view its image.

You can now [read the files or create download links](/docs/storage/read-delete). Before deploying, [configure your storage provider](/docs/fundamentals/providers) and add authentication to the upload endpoint.
