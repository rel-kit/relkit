---
title: File-system routes
description: Map nested route.ts files and named method exports to deterministic HTTP operations.
---

Every `src/routes/**/route.ts` file defines a path. Export one or more of `GET`, `POST`, `PUT`,
`PATCH`, `DELETE`, `HEAD`, and `OPTIONS`; helper exports are allowed.

| File                                    | Runtime path               | Parameter type                   |
| --------------------------------------- | -------------------------- | -------------------------------- |
| `src/routes/route.ts`                   | `/`                        | none                             |
| `src/routes/orders/route.ts`            | `/orders`                  | none                             |
| `src/routes/orders/[orderId]/route.ts`  | `/orders/:orderId`         | `string`                         |
| `src/routes/files/[...parts]/route.ts`  | `/files/*parts`            | `readonly string[]`              |
| `src/routes/docs/[[...parts]]/route.ts` | `/docs` and `/docs/*parts` | `readonly string[] \| undefined` |

`path` and `method` are not route options. Route IDs are source-scoped and may be omitted; for example,
`src/routes/orders/[orderId]/route.ts` exporting `GET` derives a safe identity equivalent to
`route.get.orders.by-order-id`. Explicit IDs remain useful when a file or export will move without
changing graph and deployment identity. Default exports and legacy `*.route.ts` files fail with
source-located migration guidance.

Matching dynamic names become reusable function input and are represented as transport path parameters
in OpenAPI and generated clients. Route mapping occurs after matching path middleware. Service-member
targets retain their service identity and share the service's ordered middleware.

Static routes win over dynamic routes, then required catch-all, then optional catch-all. The compiler
expands optional catch-all paths into two runtime registrations but keeps one authored descriptor and
one generated client operation. It rejects collisions after normalization. Route groups, parallel
routes, and intercepting routes are not supported.
