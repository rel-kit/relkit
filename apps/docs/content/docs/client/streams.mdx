## Start a stream

`useStream` exposes `start`, `cancel`, and `reset`. Query-classified streams may opt into `autoStart`;
mutation streams always require an explicit start. Classification controls start/retry policy only.
It does not make a stream a finite cache query.

The low-level client returns a single-consumer `AsyncIterable`. Work starts on the first `next()`, and
breaking iteration cancels upstream work and releases its pinned invocation generation.
