## Query finite routes

`useRoute`, `useInfiniteRoute`, `useSuspenseRoute`, and `useRouteUtils` accept only finite exposed
routes. Inputs, outputs, errors, selection, page parameters, signals, and query options are inferred
from generated declarations.

## Keep streams separate

Routes with streaming output are deliberately absent from these selectors. Use `useStream` instead.
Routes marked `client: false` have neither a route-ID RPC procedure nor a URL alias.
