A bucket stores files such as product images and invoices. Its definition gives the bucket a stable identity and sets its storage rules.

  HTTP endpoint, and verification. For the complete option contract, see
  [`defineBucket`](/docs/api/buckets#definebucket).

`id` identifies this bucket in RELKIT. Keep it stable when moving or renaming the file.

`profile` selects the storage connection named `assets` in your application configuration. That configuration determines which provider stores the files.

`visibility` controls object visibility. Authentication for an upload endpoint is configured separately.
