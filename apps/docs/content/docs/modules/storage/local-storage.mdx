## Add the provider profile

A **provider profile** is a named connection to the service that stores your files. A bucket with `profile: "assets"` uses this connection.

In development, `docker(s3(...))` starts the local MinIO recipe when the application needs this profile. It supplies binding-only credentials and loopback ports. Run `bun run check`, then `bun run dev`.

With `--local=off`, recipes stay disabled and the configured connection values must exist. For connected S3 or Cloudflare R2, follow [provider selection](/docs/modules/storage/define).
