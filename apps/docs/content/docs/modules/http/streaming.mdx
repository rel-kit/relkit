Return a sequence of values when a response should arrive incrementally instead of as one completed JSON object.

## Choose managed streaming

Declare `output: streamOf(itemSchema)` and return an async generator. The iterator is lazy,
single-consumer, schema-validates each item, and retains invocation scope until completion or
cancellation. The queue is bounded to 32 items and 4 MiB; a fully encoded item over 1 MiB fails
immediately.

## Choose a native format

Managed oRPC iterators preserve typed completion and failure. Native SSE emits `relkit-item` and an
explicit `relkit-complete` or sanitized `relkit-error`. Native text and bytes abort on a post-header
application failure; because EOF cannot always distinguish failure, use managed streaming or SSE
when callers need an explicit terminal result. Existing raw Hono routes remain the escape hatch.
