Short answers to the questions people ask first. For the bigger picture, read [Why RelKit](/docs/why-relkit).

## Is RelKit ready for production? [#production]

RelKit is pre-1.0. You can build and run a production server today, following the [deployment guides](/docs/modules/deployment), but expect one release with breaking changes before 1.0. That release will ship with a migration command and a migration guide, so you can update your code instead of rewriting it.

## Which runtimes does RelKit support? [#runtimes]

Applications run on **Bun 1.3.10 or later**. Node.js support is planned, followed by Cloudflare Workers for HTTP. Until then, choose RelKit only if you can run Bun in development and production.

## Do I need to know Effect? [#effect]

## Which schema library do I use? [#schemas]

Zod 4. New projects depend on `zod` and import `z` from it. RelKit accepts any [Standard Schema](https://standardschema.dev) library that can describe itself as JSON Schema, so ArkType, Valibot and Effect Schema work too, and you can mix them in one app. RelKit uses these schemas to validate input and output, produce the OpenAPI document and type the generated client. See [Runtime schemas](/docs/learn/concepts/schemas#choose-a-schema-library).

## Can I use my own database or libraries? [#libraries]

Yes. A function is ordinary TypeScript, so it can call any library. For SQL databases, the [Drizzle integration](/docs/modules/database) adds typed access, migrations and local Docker setup. Other integrations cover [authentication](/docs/modules/auth), [storage](/docs/modules/storage), [caching](/docs/modules/caching) and [job providers](/docs/modules/jobs/providers).

## How does RelKit work with coding agents? [#coding-agents]

New projects include an agent skill in `.agents/skills/relkit` that tells an agent where code goes, which APIs to use and how to check its work. The docs publish [`llms.txt`](https://relkit.dev/llms.txt) and [`llms-full.txt`](https://relkit.dev/llms-full.txt). Because `bun run check` validates the whole application graph, an agent gets coded errors with links instead of runtime surprises.

## Can I move an existing Express or Hono app? [#migrate]

Yes, one endpoint at a time. A Hono app can keep serving the endpoints that haven't moved yet from inside RelKit. Follow [Migrate from Express or Hono](/guides/migrate/from-express-or-hono).

## What does RelKit cost? [#license]

Nothing. RelKit is open source under the [MIT license](https://github.com/rel-kit/relkit/blob/main/LICENSE) and has no hosted service you need to pay for.

## Where do I get help? [#help]

[Open an issue](https://github.com/rel-kit/relkit/issues) with the command you ran, the `RELKIT_*` code it printed, your package versions and a small reproduction.
