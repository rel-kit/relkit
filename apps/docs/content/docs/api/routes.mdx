# Routes

## defineMiddleware

Defines one automatically discovered path-scoped HTTP middleware handler.

**Example**

```ts
import { defineMiddleware } from "@relkit/app/routes";

export default defineMiddleware("/orders/*", async (context, next) => {
  if (context.req.header("authorization") === undefined) {
    return context.json({ error: "unauthorized" }, 401);
  }
  await next();
});
```

# HTTP

## defineRoute

Defines one HTTP method exported by a nested `route.ts` module.

The compiler derives the method from the named export and the path from the
file. Omit `id` for a source-derived route identity, and omit `request` and
`responses` when schema-based inference represents the transport; explicit
mappings replace inference completely. Matching path names map into reusable
function input.

**Example**

````ts
A GET route with inferred path and query input
```ts
import { defineFunction } from "@relkit/app/functions"
import { defineRoute } from "@relkit/app/routes"
import { z } from "@relkit/app/schema"

const listOrders = defineFunction({
  id: "orders.list",
  input: z.object({ status: z.string().optional() }),
  output: z.object({ count: z.number().int() }),
  handler: async () => ({ count: 0 })
})

export const GET = defineRoute({ target: listOrders })
````

````

**Signature**

```ts
declare const defineRoute: { <const Id extends string, const Handler extends RawRouteOptions<Id>["handler"]>(options: RawRouteOptions<Id, Handler>): RawRouteDescriptor<Id, Handler>; <const Id extends string, const Target extends FunctionRefAny, const Request extends HttpRequestMapping | undefined = undefined>(options: FunctionRouteOptions<Id, Target, Request>): FunctionRouteDescriptor<Id, Target, Request>; }
````
