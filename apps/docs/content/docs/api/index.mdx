Use this section when you know which API or command you need. Package pages contain signatures, types, source links, and checked examples. The CLI page comes from the same command model as terminal help.

## Application configuration

- [defineApp](/docs/api/app#defineapp) connects your environment, server settings, and providers in `relkit.config.ts`. This is RELKIT's current application configuration API; `defineConfig` is no longer exported.
- [defineEnv](/docs/api/config#defineenv) declares typed environment values. Use the [env builders](/docs/api/config#env) to select their types, defaults, and secret handling.

For a walkthrough, read [Application configuration](/docs/learn/concepts/application) and [Environment contracts](/docs/learn/concepts/environment).
