# Application

## defineApp

Defines one immutable application topology.

**Example**

```ts
import { defineApp, defineEnv } from "@relkit/app";
export default defineApp({
  id: "orders-api",
  env: defineEnv({}),
  server: { port: 3000 },
  inspector: { port: 3210 },
});
```

**Signature**

```ts
declare const defineApp: <
  const Shape extends EnvShape,
  const Providers extends AppProviderInputs,
  const Exporters extends TelemetryExporterMap = Readonly<
    Record<string, TelemetryExporterDescriptor<string, string, object>>
  >,
>(
  options: DefineAppOptions<Shape, Providers, Exporters>,
) => ApplicationDescriptor<Shape, Providers, Exporters>;
```

[Source](https://github.com/rel-kit/relkit/blob/main/packages/app/src/define-app.ts#L56)
