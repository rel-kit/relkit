# Services

## defineService

Defines a domain's public functions and events as identity-preserving members.

**Example**

```ts
import { defineService } from "@relkit/app/services";

const orders = defineService({});
void orders;
```

**Signature**

```ts
declare const defineService: DefineService;
```
