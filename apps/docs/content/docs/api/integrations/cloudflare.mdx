## `bindings.ts`

Providers that use a Cloudflare Worker's own bindings instead of Cloudflare's HTTP APIs: a Workers
KV namespace for caches, an R2 bucket for buckets and a Durable Object for realtime. They run only in a Worker built with
`relkit build --runtime workers`; the binding name is recorded in the graph, so
`relkit deploy init cloudflare` writes the matching `kv_namespaces` and `r2_buckets` entries.

### durableObjectRealtime

Defines realtime on a Durable Object namespace whose class is `RelkitRealtimeState` from
`@relkit/cloudflare/workers`; the Workers build exports the class from the Worker. Every isolate
shares the profile's channels, retained events and presence through one object.

**Example**

```ts
import { durableObjectRealtime } from "@relkit/cloudflare";
const realtime = durableObjectRealtime({ binding: "RELKIT_REALTIME" });
```

**Signature**

```ts
declare const durableObjectRealtime: <const Binding extends string>(
  options: CloudflareBindingOptions<Binding>,
) => DurableObjectRealtimeAdapter<Binding>;
```

## `binding-providers.ts`

Cache and bucket providers on a Worker's own bindings. The binding is looked up through
`relkit/runtime/workers` on first use, so the provider can be created before the Worker's `env`
is known, and fails with the binding's name outside a Worker or when the binding is missing.
Only the binding methods RelKit needs are typed here, so the package needs no Workers types.

## `realtime-state.ts`

The parts of a Durable Object's state the classes use.

### RelkitRealtimeState (class)

Holds one realtime profile's state as a JSON document: `/read` returns it, `/compare-and-set`
replaces it only when it still equals the expected text (a Durable Object handles one event at a
time across storage awaits, so the comparison and the write are atomic), and `/wait` answers once
the document changes or the deadline passes, which lets subscribers in any isolate wait without
polling.

**Signature**

```ts
declare class RelkitRealtimeState {
  constructor(state: DurableObjectStateLike, _env: unknown);
}
```
