# Integrations

## aws

Provisions a supported S3 or Redis adapter on AWS and grants only its workload access.

**Example**

```ts
import { aws } from "@relkit/aws";
import { s3 } from "@relkit/s3";
const receipts = aws(s3(), { versioning: true });
```

**Signature**

```ts
declare const aws: <const Adapter extends AwsAdapter>(
  adapter: Adapter,
  options?: AwsOptions<Adapter>,
) => InfrastructureProviderSource<Adapter>;
```

[Source](https://github.com/rel-kit/relkit/blob/main/integrations/packages/aws/src/aws.ts#L43)
