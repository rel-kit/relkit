# Integrations

## s3

Defines an S3-compatible bucket adapter. Omit connection fields for local or infrastructure use.

**Example**

```ts
import { s3 } from "@relkit/s3";
const assets = s3({
  endpoint: "https://s3.example.com",
  bucketName: "assets",
  region: "us-east-1",
});
```

**Signature**

