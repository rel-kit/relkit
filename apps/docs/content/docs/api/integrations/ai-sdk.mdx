# Integrations

## aiSdk

Defines one AI SDK model profile without constructing a live model.

**Example**

```ts
import { aiSdk } from "@relkit/ai-sdk";
import { env } from "@relkit/app/config";
const model = aiSdk({
  provider: "openai",
  defaultModel: "gpt-5-mini",
  apiKey: env.secret("OPENAI_API_KEY"),
});
```

**Signature**

```ts

```
