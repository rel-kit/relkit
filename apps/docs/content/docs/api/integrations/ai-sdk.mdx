## `adapter-runtime.ts`

Runtime half of the AI SDK adapter for the shared agent loop: one model turn is one `generateText`
call with the bridged tools declared and no `execute`, so RelKit's loop runs every tool.

## `adapter.ts`

The Vercel AI SDK agent adapter. `aiSdk({ ... })` is the value an agent's `runtime` field holds; it
imports nothing from the AI SDK, so declaring an agent loads no SDK.

### aiSdk

Selects the Vercel AI SDK to execute an agent.

**Example**

```ts
import { aiSdk } from "@relkit/ai-sdk";
import { defineAgent } from "relkit/agents";
import { z } from "relkit/schema";

const support = defineAgent({
  id: "support",
  runtime: aiSdk(),
  model: "default",
  input: z.object({ message: z.string() }),
  output: z.object({ answer: z.string() }),
  instructions: "Reply briefly.",
  tools: [],
  limits: { maxSteps: 4, maxToolCalls: 2, timeoutMs: 30_000 },
});
void support;
```

**Signature**

```ts
declare const aiSdk: (options?: AiSdkAgentOptions) => AiSdkRuntime;
```

## `runtime-invoke.ts`

Runs one AI SDK agent invocation for the generated server: model from the agent's profile, tools
through the bridge, approvals through the run's approval handler.

### invokeAgentFunction

Invokes an AI SDK agent once and returns its validated output.

**Throws**

AgentAdapterError when the run fails or waits for an approval nobody can give.

**Example**

```ts
await invokeAgentFunction({ agent, input, tools, engine, modelRegistry });
```

**Signature**
