# Approvals

## approveApproval

Moves a pending approval to the approved state.

**Example**

```ts
import { approveApproval, createApproval } from "@relkit/app/agents";
const pending = createApproval({
  invocationId: "invocation-1",
  toolCallId: "tool-call-1",
  toolId: "cancel-order",
  sideEffect: "write",
  policy: "always",
});
void approveApproval(pending);
```

import { defineAgent } from "@relkit/app/agents";

const support = defineAgent({
  id: "support",

  output: z.object({ answer: z.string() }),
  instructions: "Reply briefly.",

  limits: { maxSteps: 4, maxToolCalls: 2, timeoutMs: 30_000 },
});
