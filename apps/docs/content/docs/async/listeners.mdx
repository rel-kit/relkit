---

Use `defineEventFunction` for work that should happen after an event, such as sending an order confirmation.

## Add a consumer

After [defining `orders.created`](/docs/events/define), create `src/orders/functions/order-confirmation.function.ts`:

<include cwd lang="ts" meta='title="src/orders/functions/order-confirmation.function.ts"'>
  ../../templates/default/v1/api/src/orders/functions/order-confirmation.function.ts
</include>

- `id` uniquely names this function.
- `event` is the exact ID of the event to consume.
- `handler` receives the event data and performs the work.

Run `bun run check` from your app's root. RelKit runs the handler when `orders.created` is published; you do not call it yourself.

To add another reaction, create another event function with a different `id` and the same `event`. For example, confirmation and analytics can both react to an order being created.

Use `defineFunction` when the caller needs a result, such as the created order. Use `defineEventFunction` for a reaction that runs separately, without returning a result to the publisher.

Try the complete [Orders example](/docs/events/first-event).
