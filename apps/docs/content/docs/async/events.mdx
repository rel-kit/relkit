Use events to react to something that happened in your app, such as an order being created. These files come from the runnable [Orders example](/docs/events/first-event).

## Define the event

<include cwd lang="ts" meta='title="src/orders/events/order-created.event.ts"'>
  ../../templates/default/v1/api/src/orders/events/order-created.event.ts
</include>

`id` uniquely names the event. `input` defines the data sent with it. `version` is optional and defaults to `1`.

## Publish it

Add the event ID to `publishes`, then call `.publish()` with the event data:

<include cwd lang="ts" meta='title="src/orders/functions/create-order.function.ts"'>
  ../../templates/default/v1/api/src/orders/functions/create-order.function.ts
</include>

Only events listed in `publishes` are available through `context.events`. Use the event ID exactly as defined.

`await ...publish(...)` waits for the event to be accepted, not for the functions consuming it to finish.

After adding the files, run `bun run check` from your app's root. Next, [add a consumer](/docs/events/consume).
