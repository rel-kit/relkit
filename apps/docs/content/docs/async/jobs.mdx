A job names a target function and input schema. Calls to the generated dependency client validate input
before enqueueing. Configure bounded retries, timeout, concurrency, and idempotency retention explicitly.

Schedules live on the job descriptor. Give each schedule a stable ID, cron expression, timezone,
validated input, and overlap policy. Durable retry, redrive, and dead-letter behavior belongs to the
selected provider. Local and test providers expose deterministic recovery controls; AWS maps durable
jobs to SQS and schedules to EventBridge Scheduler.

Handlers still execute through the common function engine, preserving validation, declared dependencies,
observability, cancellation, correlation, and causation.
