ZSYS turns typed application descriptors into one deterministic graph used by local development,
tests, generated clients, OpenAPI, the inspector, and deployment.

## The short path

```sh
bunx create-zsys@latest my-app --template api
cd my-app
bun run dev
```

Add a function with runtime schemas, export a method from `src/routes/**/route.ts`, and ZSYS derives
the route path, request transport, response contract, client, and API reference.
