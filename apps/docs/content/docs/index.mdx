## Already have an application?

Choose a [module](/docs/modules) to configure, or a [guide](/guides) for the task you want to complete. For example, [Buckets](/docs/modules/storage) explains storage configuration, while [Upload product images](/guides/storage/upload-product-images) builds an HTTP upload endpoint.

The [Inspector](/docs/modules/operations/inspector) is an optional, separately installed tool. You can complete the tutorial and verify responses from your terminal.

For terminal workflows, start with the [CLI module](/docs/modules/cli). It connects project creation, scaffolding, development, and production builds to the [command reference](/docs/api/cli).

## Documentation and source [#documentation-and-source-of-truth]

Examples come from maintained repository sources. API reference comes from TypeScript, and CLI reference comes from the command's help model.

If a step doesn't work, [report the command and its diagnostic](https://github.com/rel-kit/relkit/issues), together with your package versions and a small reproduction.
