Build an Orders API one step at a time. Each chapter continues the application from the previous chapter, so keep the same project directory.

<Callout type="note" title="Before you begin" icon="clipboard-check">
  You need basic TypeScript, a terminal, and Bun 1.3.10 or later. The first request runs locally
  without a database or cloud account.
</Callout>

<Steps>

<Step>

[Create and run an API](/docs/learn/create-an-app). Start the server and receive a greeting.

</Step>

<Step>

[Add an Orders endpoint](/docs/learn/first-route). Create an order and reject invalid input.

</Step>

<Step>

[Save orders](/docs/learn/save-orders). Persist and retrieve application data.

</Step>

<Step>

[Protect orders](/docs/learn/protect-orders). Add sign-in and require a session.

</Step>

<Step>

[Test the Orders API](/docs/learn/test-orders). Check successful requests and expected failures.

</Step>

<Step>

[Develop locally](/docs/learn/local-development). Understand validation, reloads, and optional inspection.

</Step>

<Step>

[Build and run for production](/docs/learn/build-and-run). Run the built server and verify its behavior.

</Step>

</Steps>

Start with **[Create and run an API](/docs/learn/create-an-app)**.

## Understand the concepts

After you have a working endpoint, use [Core concepts](/docs/learn/concepts) to understand functions, schemas, services, and the application graph. These pages support the tutorial; you can return to them whenever you need an explanation.
