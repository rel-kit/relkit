**Project cannot be extended by relkit add.**

## What happened

`relkit add` needs a RelKit project with a valid `package.json` and `relkit.config.ts`, and found a missing file, invalid `package.json` field or service layout problem.

## What to do

Run the command from your project root (or pass `--project-root`), and fix the file named in the message.

Reported by `create-relkit`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
