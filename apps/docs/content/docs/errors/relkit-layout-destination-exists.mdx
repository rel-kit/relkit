**Layout migration target already exists.**

## What happened

`relkit migrate layout` wants to move a file to a path that already exists.

## What to do

Rename or remove the file at the path in the message, then run `relkit migrate layout` again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.
