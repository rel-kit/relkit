**Realtime channel on Vercel needs an external provider.**

## What happened

`relkit check` found `vercel.json` in the project and a channel that clients subscribe to whose realtime profile uses the local provider, or no provider. Vercel functions keep no state between invocations and run as many instances as traffic needs, so subscribers would miss events published from another instance.

## What to do

Select an external realtime provider for the channel's profile, such as `redisRealtime()` from `@relkit/redis` with a Redis the deployment can reach, or deploy the app to a container target such as Railway. Vercel functions also accept no WebSocket upgrades; the Vercel guide describes the realtime limits.

Reported by `@relkit/cli`, `relkit/diagnostics`.
