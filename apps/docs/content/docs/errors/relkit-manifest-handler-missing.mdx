**Function has no handler in the build.**

## What happened

A function in the app graph has no handler RelKit can call, either while building or in the built manifest.

## What to do

Make sure the function has a `handler` and is exported from its file, then run `relkit build` again.

Reported by `@relkit/cli`, `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
