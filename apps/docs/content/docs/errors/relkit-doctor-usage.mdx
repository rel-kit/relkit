**Invalid relkit doctor arguments.**

## What happened

`relkit doctor` received an unknown option, an option without its value, an invalid port or the retired `--inspector-port` option.

## What to do

Run `relkit doctor --help` to see the accepted options. Set the inspector port with `inspector.connection.port` in `relkit.config.ts`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
