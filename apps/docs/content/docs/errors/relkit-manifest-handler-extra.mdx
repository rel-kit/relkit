**Build registers an unknown function.**

## What happened

The runtime manifest registers a function that is not in the app graph, usually because build files are from different builds.

## What to do

Run `relkit build` again and deploy all of its output together.

Reported by `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
