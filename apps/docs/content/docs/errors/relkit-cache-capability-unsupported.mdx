**Cache provider does not support this operation.**

## What happened

Your code called a cache operation that the selected cache provider does not support.

## What to do

Use a cache provider that supports this capability, or replace the call with operations it does support, such as `get` and `set`.

Reported by `@relkit/cache`, `@relkit/diagnostics`.
