**Invalid relkit migrate arguments.**

## What happened

`relkit migrate` received an unknown subcommand or option, an option without its value, or both `--write` and `--rollback`.

## What to do

Run `relkit migrate layout` with `--write` or `--rollback <path>`, not both.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
