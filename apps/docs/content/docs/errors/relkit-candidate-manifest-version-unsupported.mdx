**Reloaded app uses an unsupported manifest version.**

## What happened

During `relkit dev`, the reloaded app reported a runtime manifest version this CLI does not support.

## What to do

Put all `@relkit/*` packages on the same version, run `bun install`, then restart `relkit dev`.

Reported by `@relkit/diagnostics`, `@relkit/supervisor`.

See [all error codes](/docs/errors).
