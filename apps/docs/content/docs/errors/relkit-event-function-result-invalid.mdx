**Event function returns a value.**

## What happened

An event function's handler returns a value on success. Event functions must return nothing.

## What to do

Return `void` from the handler on success, and use declared errors for failures.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
