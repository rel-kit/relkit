**Invalid relkit start arguments.**

## What happened

`relkit start` received an option it does not accept, an option without its value, or a port outside 0 to 65535.

## What to do

Run `relkit start --help` to see the accepted options, then run the command again.

Reported by `relkit/diagnostics`.

See [all error codes](/docs/errors).
