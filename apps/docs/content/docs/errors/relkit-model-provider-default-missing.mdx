**Model provider has no default model.**

## What happened

A model selector names only a provider, and that provider has no default model configured.

## What to do

Use a full selector such as `"openai:gpt-4o"`, or set a default model for that provider.

Reported by `@relkit/agents`, `@relkit/compiler`, `@relkit/diagnostics`, `@relkit/engine`.

See [all error codes](/docs/errors).
