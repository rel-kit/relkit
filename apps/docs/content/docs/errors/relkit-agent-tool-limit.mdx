**Agent hit its tool-call limit.**

## What happened

The agent made as many tool calls as its limit allows without producing a final answer.

## What to do

Raise the agent's `maxToolCalls` limit, or give it clearer instructions so it needs fewer tool calls.

Reported by `@relkit/langchain`, `relkit/diagnostics`.
