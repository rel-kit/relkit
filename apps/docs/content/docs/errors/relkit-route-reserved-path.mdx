**Route uses a reserved path.**

## What happened

A route path starts with `/_relkit`, which RelKit keeps for its own endpoints.

## What to do

Move the route to a path that does not start with `/_relkit`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
