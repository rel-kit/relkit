**Job changes are turned off.**

## What happened

A local job action, such as a retry or cancel, was requested while changes are turned off, which is always the case in production mode.

## What to do

Run the action against a development or test environment. In production, use `relkit jobs retry` or `relkit jobs cancel`.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
