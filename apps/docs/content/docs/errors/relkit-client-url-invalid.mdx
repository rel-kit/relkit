**Client base URL is not HTTP or HTTPS.**

## What happened

`relkit client pull` needs an `http://` or `https://` base URL for the server.

## What to do

Pass a full URL such as `http://localhost:3000`, then run the command again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
