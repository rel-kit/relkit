**Destination path is invalid.**

## What happened

The destination for the new project is not a valid local path, is not a directory, or could not be read.

## What to do

Choose a destination path whose parent folders exist and are directories you can read.

Reported by `@relkit/diagnostics`, `create-relkit`.

See [all error codes](/docs/errors).
