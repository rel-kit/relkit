**logging of a task is deprecated.**

## What happened

A task sets `logging` in `defineTask`. The option never had an effect: no jobs backend reads its `level` or its `redact` list. It is still accepted, and `relkit check` warns for each task that sets it; the check still passes.

## What to do

Remove `logging` from the task. To keep a value out of recorded telemetry, list its key in `telemetry.redaction.redactKeys` of `defineApp`; to log less, set the application's log level.

Reported by `@relkit/cli`, `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
