**The project does not install the RelKit CLI.**

## What happened

The `relkit` command runs the `@relkit/cli` package installed in your project, and the project does not declare or install it.

## What to do

Run `bun add -d @relkit/cli` in the project, then run the command again.

Reported by `relkit/diagnostics`.

See [all error codes](/docs/errors).
