**No development session is running.**

## What happened

`relkit mcp` found no running `relkit dev` session for this project with the Inspector bridge enabled, so it had nothing to connect to.

## What to do

Run `relkit add inspector` once if the project does not enable the Inspector, start `relkit dev` in the project, then start `relkit mcp` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
