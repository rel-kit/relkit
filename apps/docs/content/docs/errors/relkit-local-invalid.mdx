**Local services setup is invalid.**

## What happened

Your app's local service setup is inconsistent: the app ID is invalid or services need more than one local runner.

## What to do

Check your app's ID and local integrations in `relkit.config.ts`, then run `relkit check` and try again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
