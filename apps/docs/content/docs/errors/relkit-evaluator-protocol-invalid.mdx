**File loader returned an unreadable result.**

## What happened

The process that loads your source files exited without a valid result. Calling `process.exit` or writing to stdout at import time can cause this.

## What to do

Remove top-level `process.exit` calls and stdout writes from your source files. If it persists, report this on the RelKit issue tracker with the full output.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
