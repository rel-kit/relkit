**Error has no ID.**

## What happened

A `defineError` call has no `id`. An error's ID is the public `code` in API responses, so it must not change when the file moves.

## What to do

Add the `id` the message suggests; it is the ID earlier versions inferred, so clients see the same code.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
