**Job submission failed.**

## What happened

The job could not be submitted. For example, the input no longer matches the job build that was selected, or the provider rejected it.

## What to do

Read the cause in the output. If you changed the job's input schema, rebuild and restart so callers and workers use the same build.

Reported by `@relkit/diagnostics`, `@relkit/jobs`.

See [all error codes](/docs/errors).
