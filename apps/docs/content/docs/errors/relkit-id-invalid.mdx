**ID is not valid.**

## What happened

A definition ID is not a valid stable ID, or an ID inside a domain does not start with the domain name.

## What to do

Use letters and numbers joined by dots, hyphens or underscores. Inside a domain, start IDs with the domain name and give the service the same ID as the domain.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
