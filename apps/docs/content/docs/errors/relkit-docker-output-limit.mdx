**Docker output is too large.**

## What happened

A Docker command printed more output than RelKit is willing to read.

## What to do

Run the Docker command yourself to see its output. Report this on the RelKit issue tracker with the full output if it keeps happening.

Reported by `@relkit/docker`, `relkit/diagnostics`.
