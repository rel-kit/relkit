**Build was made by another RelKit version.**

## What happened

The runtime manifest was generated by a different version of RelKit than the one running the app.

## What to do

Run `relkit build` with the same RelKit version you run in production, then deploy the new output.

Reported by `relkit/diagnostics`, `relkit/engine`, `relkit/runtime-hono`.

See [all error codes](/docs/errors).
