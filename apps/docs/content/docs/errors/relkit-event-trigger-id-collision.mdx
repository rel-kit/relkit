**Event trigger ID is already taken.**

## What happened

An event function needs a trigger ID to receive its event, but another definition in your app already uses that ID.

## What to do

Rename the other definition that uses the ID shown in the error.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
