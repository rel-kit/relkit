**Event changes are turned off.**

## What happened

A local event action, such as a retry, was requested while changes are turned off, which is always the case in production mode.

## What to do

Run the action against a development or test environment. In production, use your event provider's own tools.

Reported by `@relkit/diagnostics`, `@relkit/providers-local`.
