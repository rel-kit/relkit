**Invalid database migration configuration.**

## What happened

`relkit db migrate` received invalid arguments, or the Drizzle configuration file could not be used.

## What to do

Run `relkit db migrate [--config <path>]` and make sure the file (default `drizzle.config.ts`) exports a valid Drizzle configuration.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
