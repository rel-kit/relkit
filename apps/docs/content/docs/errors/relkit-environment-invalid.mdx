**Environment variables are invalid at startup.**

## What happened

Your built server could not start because one or more environment variables are missing or do not match your environment definition.

## What to do

Run `relkit env check` to see which variables are wrong, set them, then start the server again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
