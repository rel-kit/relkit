**RelKit CLI missing in the new project.**

## What happened

The project was generated, but `node_modules/.bin/relkit` was not found, so RelKit could not run its first project check.

## What to do

Run `bun install` in the new project, then run `bun run check`.

Reported by `@relkit/diagnostics`, `create-relkit`.

See [all error codes](/docs/errors).
