**RelKit CLI missing in the new project.**

## What happened

The project was generated, but `node_modules/.bin/relkit` was not found, so RelKit could not run its first project check.

## What to do

Install the new project's dependencies, then run its `check` script (`npm run check`, `pnpm run check` or `bun run check`).

Reported by `create-relkit`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
