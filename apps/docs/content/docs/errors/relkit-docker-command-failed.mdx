**Docker command failed.**

## What happened

A Docker command run by RelKit exited with an error.

## What to do

Check the exit code and Docker's output, then run `docker ps` and `docker logs` for the container to see what went wrong.

Reported by `@relkit/docker`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
