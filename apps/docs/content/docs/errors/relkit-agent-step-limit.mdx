**Agent hit its step limit.**

## What happened

The agent used every step its limit allows without producing a final answer.

## What to do

Raise the agent's step limit, or give it clearer instructions or fewer tools so it can finish sooner.

Reported by `@relkit/langchain`, `relkit/agent-adapters`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
