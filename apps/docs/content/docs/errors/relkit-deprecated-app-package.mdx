**@relkit/app is deprecated.**

## What happened

The application imports `@relkit/app`. RelKit's core package is now `relkit`, and the final `@relkit/app` release only re-exports it so existing imports keep working.

## What to do

Run `relkit migrate` to rewrite `@relkit/app` imports to `relkit`, then remove `@relkit/app` from your dependencies.

Reported by `@relkit/app`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
