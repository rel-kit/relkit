**relkit migrate needs a project folder.**

## What happened

The folder passed to `relkit migrate` has no `package.json`.

## What to do

Run `relkit migrate` in your project folder, or pass it with `--project-root`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
