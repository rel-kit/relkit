**Invalid relkit env arguments.**

## What happened

`relkit env` received an unknown subcommand or option, more than one variable name, or an option that only `env example` accepts.

## What to do

Run `relkit env --help` to see the accepted subcommands and options, then run the command again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
