**Integration package does not match.**

## What happened

An integration package does not register what the app expects, or two packages claim the same integration ID.

## What to do

Install the integration package version that matches your RelKit version, and remove duplicate integration packages.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
