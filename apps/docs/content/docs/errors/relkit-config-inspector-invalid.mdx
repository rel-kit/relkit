**Inspector settings are invalid.**

## What happened

The `inspector` settings in `relkit.config.ts` are not valid, or they use the older `inspector.port` setting.

## What to do

Use `enabled`, `connection.host`, `connection.port` and `maxPreviewBytes`. Replace `inspector.port` with `inspector.connection.port`, and set the UI port with `relkit-inspector --port`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
