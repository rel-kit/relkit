**Expected graph hash has the wrong format.**

## What happened

The value passed to `--hash` is not in the form `sha256:` followed by 64 lowercase hex characters.

## What to do

Copy the hash exactly as `relkit graph print` shows it, then run the command again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
