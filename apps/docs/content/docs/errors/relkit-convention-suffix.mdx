**File name lacks the recommended suffix.**

## What happened

A definition file does not end with the suffix RelKit recommends for its kind, such as `.function.ts` or `.job.ts`.

## What to do

Rename the file to use the suffix shown in the warning.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
