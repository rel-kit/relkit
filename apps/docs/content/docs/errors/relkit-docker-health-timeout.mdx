**Docker container did not become healthy.**

## What happened

A local service container did not report healthy before the wait time ran out.

## What to do

Run `docker logs` for the container to see if it is still starting or stuck. Free up resources or retry if it is slow to start.

Reported by `@relkit/docker`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
