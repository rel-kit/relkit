**Item cannot take this action now.**

## What happened

The action does not fit the item's current state, such as retrying something that has not failed or cancelling something that already finished.

## What to do

Refresh the Inspector to see the item's current state, then pick an action that fits it.

Reported by `relkit/diagnostics`, `relkit/inspector-api`.

See [all error codes](/docs/errors).
