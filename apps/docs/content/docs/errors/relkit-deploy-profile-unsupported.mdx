**Provider profile does not support a feature.**

## What happened

Your app uses a capability that the selected deployment provider profile does not implement.

## What to do

Choose a provider profile that supports this capability, or remove the feature named in the message from your app.

Reported by `relkit/deploy`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
