**Reloaded app environment is not ready.**

## What happened

During `relkit dev`, the reloaded app started but reported that its environment variables are not valid yet.

## What to do

Run `relkit env check` to see which variables are missing or invalid, fix them, then save a file to reload.

Reported by `@relkit/cli`, `relkit/diagnostics`.
