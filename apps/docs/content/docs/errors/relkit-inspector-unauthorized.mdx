**Inspector request is not authorized.**

## What happened

A request to the Inspector endpoints was rejected because it had no valid credentials.

## What to do

Send the configured bearer token with the request, or check the `bearerToken` or `authorize` option on the Inspector endpoints.

Reported by `@relkit/diagnostics`, `@relkit/inspector-api`, `@relkit/runtime-hono`.

See [all error codes](/docs/errors).
