**Stream item is too large.**

## What happened

A stream item was larger than the configured size limit after encoding.

## What to do

Split the data into smaller items, or raise the stream's item size limit.

Reported by `relkit/diagnostics`, `relkit/invocation`.

See [all error codes](/docs/errors).
