**Provider failed to shut down.**

## What happened

One or more providers threw an error while the app was shutting down.

## What to do

Check the logs for the provider that failed. Open connections may need to be closed by the service itself.

Reported by `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
