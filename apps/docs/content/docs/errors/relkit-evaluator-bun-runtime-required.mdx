**A source file imports a module that needs Bun.**

## What happened

RelKit loads your source files on the runtime the command runs on. The command runs on Node, and a file imports a module that exists only on Bun, such as `bun:sqlite` or `drizzle-orm/bun-sql`.

## What to do

Run the command with Bun, for example `bun --bun run check`, or open the database with a client that selects the driver for the runtime: `openSqliteDatabase` from `@relkit/drizzle/sqlite`, `openPostgresDatabase` from `@relkit/drizzle/pg` or `openMysqlDatabase` from `@relkit/drizzle/mysql`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
