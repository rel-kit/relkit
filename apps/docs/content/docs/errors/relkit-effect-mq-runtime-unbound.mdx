**effect-mq jobs are not connected.**

## What happened

A job operation ran before the effect-mq provider was connected to its database.

## What to do

Configure the effect-mq jobs profile with a Postgres URL in `relkit.config.ts` for this environment.

Reported by `@relkit/diagnostics`, `@relkit/effect-mq`.

See [all error codes](/docs/errors).
