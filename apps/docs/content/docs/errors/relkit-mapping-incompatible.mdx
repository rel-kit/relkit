**Route request does not match the function input.**

## What happened

A route's request mapping, or a path parameter it reads, does not fit the input schema of the function it calls.

## What to do

Add the missing field to the function's input schema, or define an explicit request mapping on the route.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
