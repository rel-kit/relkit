**Import crosses a domain boundary.**

## What happened

A file imports code from inside another domain instead of going through its public service.

## What to do

Import what you need from the other domain's public service, or move the shared code to a place both domains can use.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
