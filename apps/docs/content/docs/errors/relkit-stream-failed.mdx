**Stream ended with an error.**

## What happened

A server stream ended early because the application code producing it threw an error.

## What to do

Check the server logs for the error thrown while producing the stream and fix it.

Reported by `@relkit/client`, `relkit/diagnostics`, `relkit/runtime-hono`.
