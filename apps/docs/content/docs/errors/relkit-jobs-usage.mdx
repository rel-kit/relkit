**Invalid relkit jobs arguments.**

## What happened

`relkit jobs` received an unknown subcommand or option, or the `PORT` environment variable is not a valid port.

## What to do

Run `relkit jobs --help` to see the accepted subcommands and options, and check `PORT` if you set it.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
