**Agent function has no runtime.**

## What happened

The function RelKit generates for an agent was called before an agent runtime was set up for it.

## What to do

Make sure the agent's integration package, such as `@relkit/langchain`, is installed and the agent is part of the app, then run `relkit build` again.

Reported by `@relkit/agents`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
