**Provider connection settings are invalid.**

## What happened

RelKit could not work out the connection settings for one of the app's providers.

## What to do

Check the provider's connection settings and environment variables, then restart the app.

Reported by `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
