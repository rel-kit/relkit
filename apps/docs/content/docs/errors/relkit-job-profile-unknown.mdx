**Job profile is not configured.**

## What happened

The job client asked for a provider profile that is not in its configuration.

## What to do

Add the profile to the jobs provider configuration, or use the name of a profile that already exists.

Reported by `@relkit/diagnostics`, `@relkit/jobs`.

See [all error codes](/docs/errors).
