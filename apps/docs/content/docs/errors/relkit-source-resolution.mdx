**Import cannot be resolved.**

## What happened

RelKit cannot resolve an import in your app, or cannot read the path aliases in `tsconfig.json`.

## What to do

Check the import path and the `paths` aliases in `tsconfig.json`, then run `relkit check`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
