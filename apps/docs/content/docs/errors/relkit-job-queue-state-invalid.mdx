**Local job queue is damaged.**

## What happened

The local job provider found a queue entry with inconsistent data that it cannot use.

## What to do

Stop the app and delete the jobs folder under `.relkit/state`, then start again. This clears local jobs.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
