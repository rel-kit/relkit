**Task failed with a non-error value.**

## What happened

A task handler threw something that is not an `Error`, so RelKit has no error name or message to report.

## What to do

Throw an `Error` or one of the task's declared errors instead of a string or other value.

Reported by `@relkit/testing`, `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
