**Model provider environment is not set up.**

## What happened

A model provider is missing an API key or other environment variable it needs.

## What to do

Set the environment variables the provider needs, for example with `relkit env`, then restart the app.

Reported by `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
