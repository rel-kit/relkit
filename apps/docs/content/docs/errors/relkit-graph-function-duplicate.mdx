**Function ID is used twice.**

## What happened

Two functions in the app have the same ID, so RelKit cannot tell which one to call.

## What to do

Rename one of the functions or move it to another service so every function ID is unique, then run `relkit check`.

Reported by `@relkit/diagnostics`, `@relkit/engine`.

See [all error codes](/docs/errors).
