**Task has unclear job bindings.**

## What happened

A task has more than one default job, or RelKit cannot create a job for it automatically because its export name is not unique.

## What to do

Mark at most one job per task as `default`, or define the job for the task explicitly with `defineJob` and a unique `name`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
