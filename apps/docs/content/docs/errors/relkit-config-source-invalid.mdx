**Source setting is invalid.**

## What happened

The `source` setting in `relkit.config.ts` is not valid. RelKit always reads your code from `src/**/*.ts`.

## What to do

Remove `source` from `relkit.config.ts` and keep your app code under `src/`.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
