**Runtime integration plan version is not supported.**

## What happened

The generated runtime integration plan uses a format version this RelKit version does not support.

## What to do

Put all `@relkit/*` packages on the same version, then run `relkit check` to regenerate it.

Reported by `relkit/contracts`, `relkit/diagnostics`, `relkit/runtime-hono`.

See [all error codes](/docs/errors).
