**Config path is invalid.**

## What happened

A path in `relkit.config.ts` is empty or is not a valid relative path.

## What to do

Use a relative path inside your project, written with forward slashes.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
