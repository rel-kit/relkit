**Database migration failed.**

## What happened

A migration statement failed. RelKit did not retry it, and a rollback is not guaranteed.

## What to do

Check your database connection settings and the failing SQL in the output, fix them, then run `relkit db migrate` again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.
