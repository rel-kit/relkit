**Reloaded app does not match the build.**

## What happened

During `relkit dev`, the reloaded app reported a different set of active features than the build RelKit produced.

## What to do

Stop `relkit dev` and start it again. If this keeps happening, report this on the RelKit issue tracker with the full output.
