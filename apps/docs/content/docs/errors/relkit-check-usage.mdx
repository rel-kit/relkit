**Invalid relkit check arguments.**

## What happened

`relkit check` received an option it does not accept, an option without its value, or a port outside 0 to 65535.

## What to do

Run `relkit check --help` to see the accepted options, then run the command again.

Reported by `@relkit/diagnostics`.

See [all error codes](/docs/errors).
