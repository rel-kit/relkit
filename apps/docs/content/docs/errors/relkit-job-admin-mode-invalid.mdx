**Job admin mode is not valid.**

## What happened

The local job tools were started with a mode other than development, test or production.

## What to do

Set the mode to `development`, `test` or `production`.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
