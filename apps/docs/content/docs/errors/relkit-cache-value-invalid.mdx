**Cache value is not valid JSON.**

## What happened

A value written to the local cache cannot be turned into plain JSON.

## What to do

Store JSON data only, such as strings, numbers, arrays and plain objects, without `undefined`, functions, class instances or `NaN`.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
