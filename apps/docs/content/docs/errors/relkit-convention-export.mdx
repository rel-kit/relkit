**Definition file has no default export.**

## What happened

A definition file does not default-export its definition. RelKit recommends one default export per file so each file has a clear entry.

## What to do

Add `export default` for the definition named in the warning.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
