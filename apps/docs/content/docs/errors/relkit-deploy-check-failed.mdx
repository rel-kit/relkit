**Project check failed before deployment.**

## What happened

`relkit deploy` checks your project first, and the check failed or the project changed while planning.

## What to do

Run `relkit check`, fix the errors it reports, then run `relkit deploy` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
