**Job data is not in a supported format.**

## What happened

Stored or received job data is badly formed, too large, or uses a format version this RelKit version does not support.

## What to do

Update all `@relkit/*` packages so the sender and worker use the same version. If it still fails, report this on the RelKit issue tracker.

Reported by `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
