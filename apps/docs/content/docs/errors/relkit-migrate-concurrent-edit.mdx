**A file changed while relkit migrate was writing.**

## What happened

A file that `relkit migrate --write` was about to change no longer matched the preview, so the migration stopped and restored the files it had already written.

## What to do

Stop other tools that edit the project, then run `relkit migrate --write` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
