**Progress update does not match its schema.**

## What happened

A task emitted a progress value that failed the progress schema or cannot be turned into plain JSON.

## What to do

Check the message and send progress values that match the task's progress schema, using JSON data only.

Reported by `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
