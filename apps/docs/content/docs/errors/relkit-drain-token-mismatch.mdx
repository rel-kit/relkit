**Reload targeted the wrong app version.**

## What happened

During `relkit dev`, a request to stop the previous version of your app did not match the version currently running.

## What to do

Restart `relkit dev`. If this keeps happening, report this on the RelKit issue tracker with the full output.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
