**Tool is not registered.**

## What happened

A tool was called by an ID that is not registered in the app.

## What to do

Check the tool ID for typos and make sure the tool is defined and included in the app, then run `relkit build` again.

Reported by `@relkit/langchain`, `relkit/diagnostics`, `relkit/tools`.

See [all error codes](/docs/errors).
