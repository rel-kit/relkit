**TypeScript compiler could not run.**

## What happened

`relkit check` type-checks by running your project's own TypeScript compiler (`tsc` from `typescript`, or `tsgo`), and it is not installed or exited without reporting any errors.

## What to do

Add `typescript` 5.9 or 7 to your devDependencies, install, then run `relkit check` again. If it is installed, run `tsc --noEmit` to see why it fails.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
