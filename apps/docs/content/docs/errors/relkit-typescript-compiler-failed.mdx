**TypeScript compiler could not run.**

## What happened

`relkit check` type-checks by running your project's own TypeScript compiler (`tsc` from `typescript`, or `tsgo`), and it exited without reporting any errors, for example because its installation is broken.

## What to do

Run `tsc --noEmit` in the project to see why the compiler fails, reinstall `typescript` (5.9 or 7) if needed, then run `relkit check` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
