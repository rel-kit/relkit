**Progress sent after the function finished.**

## What happened

A function reported progress after it had already returned or failed.

## What to do

Report progress only before the function returns. Await any background work that reports progress.

Reported by `@relkit/diagnostics`, `@relkit/invocation`.

See [all error codes](/docs/errors).
