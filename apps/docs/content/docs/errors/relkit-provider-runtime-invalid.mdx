**Provider does not fit the job type.**

## What happened

A jobs provider does not match the kind of job it runs, for example a task job bound to a provider that is not a task jobs adapter.

## What to do

Bind the job to a jobs provider that supports its kind, then run `relkit build` again.

Reported by `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
