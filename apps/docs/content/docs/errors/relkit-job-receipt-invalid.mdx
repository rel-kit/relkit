**Job provider returned an invalid confirmation.**

## What happened

The job provider accepted a submission, but its confirmation is missing the run identity or does not match the job that was sent.

## What to do

Update the job provider package to a version that matches your `@relkit/jobs` version. If it still fails, report this on the RelKit issue tracker.

Reported by `@relkit/diagnostics`, `@relkit/jobs`.

See [all error codes](/docs/errors).
