**Inspector and app versions differ.**

## What happened

The Inspector and the service handling the action use different protocol versions.

## What to do

Update all `@relkit/*` packages to the same version, then restart the app and refresh the Inspector.

Reported by `@relkit/inspector-api`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
