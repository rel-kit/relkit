**Observability query is not valid.**

## What happened

A query for logs, spans or events has a field RelKit cannot use, such as an unknown order, a bad cursor or a limit out of range.

## What to do

Check the message for the field that failed and correct it. Pass cursors unchanged from the previous page.

Reported by `@relkit/diagnostics`, `@relkit/inspector`, `@relkit/inspector-api`, `@relkit/observability`, `@relkit/observability-local`.

See [all error codes](/docs/errors).
