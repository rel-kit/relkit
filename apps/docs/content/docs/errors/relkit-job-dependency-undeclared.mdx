**Job is not declared on this function.**

## What happened

A function enqueued a job that is not listed in its dependencies.

## What to do

Add the job to the function's `dependencies` so RelKit knows the function may enqueue it.

Reported by `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
