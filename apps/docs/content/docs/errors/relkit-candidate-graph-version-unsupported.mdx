**Reloaded app uses an unsupported graph version.**

## What happened

During `relkit dev`, the reloaded app reported a graph format version this CLI does not support.

## What to do

Put all `@relkit/*` packages on the same version, run `bun install`, then restart `relkit dev`.

Reported by `@relkit/diagnostics`, `@relkit/supervisor`.

See [all error codes](/docs/errors).
