**relkit deploy init would overwrite a different file.**

## What happened

`relkit deploy init <target>` found a file it writes, such as `railway.json` or `Dockerfile`, that already exists with different content, so it wrote nothing.

## What to do

Compare the existing file with what the target needs, keep any change you still want elsewhere, then run the command again with `--force` to replace it.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
