**Action ID reused for a different action.**

## What happened

An Inspector action was sent with an operation ID that was already used for a different request.

## What to do

Use a new operation ID for each distinct action. Reuse an ID only to retry the exact same action.

Reported by `@relkit/inspector-api`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
