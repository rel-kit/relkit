**Inspector action target is invalid.**

## What happened

The Inspector action named a target that is not valid for that action.

## What to do

Refresh the Inspector and start the action again from the item itself.

Reported by `@relkit/diagnostics`, `@relkit/inspector-api`.

See [all error codes](/docs/errors).
