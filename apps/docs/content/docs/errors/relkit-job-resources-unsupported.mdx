**Task resources are invalid.**

## What happened

A task's `resources` option does not set positive CPU and memory values.

## What to do

Set positive CPU and memory values in the task's `resources`, or remove the option.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
