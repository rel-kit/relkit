**Deployment plan version is not supported.**

## What happened

The saved deployment plan was written in a format version this RelKit version does not support.

## What to do

Run `relkit deploy preview` to create a fresh plan, then deploy again.

Reported by `@relkit/deploy`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
