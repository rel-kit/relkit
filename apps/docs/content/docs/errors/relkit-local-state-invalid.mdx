**Local state is invalid.**

## What happened

A file in the project's `.relkit/state` folder is in the wrong place, too large or not valid.

## What to do

Run `relkit local reset` to clear local state. Do not link or move files inside `.relkit/state` by hand.

Reported by `@relkit/local`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
