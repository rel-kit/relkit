**Local job store is not usable.**

## What happened

The local job store has a record it cannot read, or it was used after it closed.

## What to do

Restart the app. If it still fails, stop the app and delete the jobs folder under `.relkit/state`. This clears local jobs.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
