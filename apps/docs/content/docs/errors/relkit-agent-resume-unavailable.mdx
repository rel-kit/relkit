**No agent run is waiting.**

## What happened

A resume request named a thread that has no run waiting for an approval decision.

## What to do

Resume only threads whose last run returned the `interrupted` status, and send the decision once.

Reported by `relkit/agent-adapters`, `relkit/diagnostics`.
