**Route file exports are invalid.**

## What happened

A route file exports no HTTP method, exports a name that is not a method, or exports something other than a typed route.

## What to do

Export only named HTTP methods, each created with `defineRoute`, from the route file.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
