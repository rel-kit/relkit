**Git status could not be read.**

## What happened

`relkit migrate layout` needs Git to check for uncommitted changes, and the Git command failed.

## What to do

Make sure `git` is installed and works in the project directory, then run the command again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
