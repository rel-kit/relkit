**Agent thread is waiting for approval.**

## What happened

A new run started on a thread whose previous run is still waiting for an approval decision.

## What to do

Approve or deny the pending tool call with a resume request before starting another run on the thread.

Reported by `@relkit/ai-sdk`, `relkit/agent-adapters`, `relkit/diagnostics`.
