**Function called itself in a loop.**

## What happened

A function call was blocked because it would call a function that is already on the call stack.

## What to do

Check the reported cycle and break the loop, for example by moving the repeated step into a job or a separate function.

Reported by `@relkit/diagnostics`, `@relkit/invocation`.

See [all error codes](/docs/errors).
