**More than one development session is running.**

## What happened

`relkit mcp` found several running `relkit dev` sessions for this project and cannot choose one.

## What to do

Stop the extra `relkit dev` processes so one session remains, then start `relkit mcp` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
