**Build files are out of sync.**

## What happened

The generated manifest does not match the app graph it was built with, usually because some build files come from an older build.

## What to do

Run `relkit build` again and deploy all of its output together.

Reported by `@relkit/compiler`, `relkit/diagnostics`, `relkit/engine`, `relkit/runtime-hono`.
