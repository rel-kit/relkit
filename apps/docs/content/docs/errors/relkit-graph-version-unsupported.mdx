**Application graph version is not supported.**

## What happened

The application graph was generated in a format version this RelKit version does not support.

## What to do

Put all `@relkit/*` packages on the same version, then run `relkit check` or `relkit build` to regenerate it.

Reported by `@relkit/cli`, `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
