**Trigger.dev cannot resume from a cursor.**

## What happened

A watch on a Trigger.dev run asked to resume from a position, which Trigger.dev run watches do not support.

## What to do

Start the watch from the beginning instead of passing a resume position.

Reported by `@relkit/diagnostics`, `@relkit/trigger`.

See [all error codes](/docs/errors).
