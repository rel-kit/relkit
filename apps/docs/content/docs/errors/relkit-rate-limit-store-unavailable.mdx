**Rate-limit store is not usable.**

## What happened

The cache provider used for rate limiting does not support the required counter operations, or returned an invalid count.

## What to do

Use a cache provider that supports `get`, `increment` and `delete` for the rate-limit profile.

Reported by `@relkit/diagnostics`, `@relkit/runtime-hono`.

See [all error codes](/docs/errors).
