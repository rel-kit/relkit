**Client job contract is out of date.**

## What happened

The client was built against a different version of the app's public job contract than the server is running.

## What to do

Rebuild the client and the server from the same source with `relkit build`, then deploy them together.

Reported by `@relkit/diagnostics`, `@relkit/runtime-hono`.

See [all error codes](/docs/errors).
