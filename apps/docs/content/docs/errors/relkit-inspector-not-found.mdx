**Inspector item not found.**

## What happened

The Inspector asked for a node, run or other item that does not exist in the running app.

## What to do

Refresh the Inspector. If the app was rebuilt or restarted, the item may no longer exist.

Reported by `@relkit/inspector-api`, `relkit/diagnostics`, `relkit/runtime-hono`.

See [all error codes](/docs/errors).
