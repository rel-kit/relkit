**Event function sets an unsupported option.**

## What happened

An event function declares an option it cannot have. Its input always comes from the event, and it returns nothing on success.

## What to do

Remove the option named in the error from `defineEventFunction`.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
