**Task-backed jobs are not supported yet.**

## What happened

Your app defines task-backed jobs, and the runtime that runs them is not available in this RelKit version.

## What to do

Run these jobs through a jobs integration such as `@relkit/inngest` or `@relkit/trigger`, or remove them, then build again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
