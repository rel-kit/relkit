**Docker setting is invalid.**

## What happened

A value used to build a Docker command, such as an image, container name or port, is not valid.

## What to do

Check the local service's Docker settings in `relkit.config.ts` for invalid names, images or ports.

Reported by `@relkit/diagnostics`, `@relkit/docker`.

See [all error codes](/docs/errors).
