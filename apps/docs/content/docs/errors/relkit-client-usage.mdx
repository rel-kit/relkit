**Invalid relkit client arguments.**

## What happened

`relkit client` received an unknown subcommand or option, or is missing the base URL or `--out` directory.

## What to do

Run `relkit client pull <baseUrl> --out <directory>` or `relkit client check <baseUrl> --out <directory>`.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
