**ID cannot be worked out from the source.**

## What happened

RelKit could not take a stable ID from how this definition is exported or assigned, for example when it is built inside a loop or function.

## What to do

Give the definition an explicit `id`, or export it as a named constant or default export.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
