**Invalid relkit dev arguments.**

## What happened

`relkit dev` received an option it does not accept, an option without its value, or an invalid `--port`, `--local` or `--log-level` value.

## What to do

Run `relkit dev --help` to see the accepted options, then run the command again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
