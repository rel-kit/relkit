**Project check failed after relkit add.**

## What happened

`relkit add` made its changes, but the follow-up `bun run check` reported errors, so the changes were not kept.

## What to do

Run `relkit check` to see the errors in your project, fix them, then run `relkit add` again.

Reported by `create-relkit`, `relkit/diagnostics`.
