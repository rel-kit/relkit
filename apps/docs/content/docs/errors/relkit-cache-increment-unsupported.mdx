**Cache increment needs a numeric value.**

## What happened

Your code called `increment` on a cache whose value schema is not a number.

## What to do

Use a cache with a numeric value schema for counters, or read, change and `set` the value instead.

Reported by `relkit/cache`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
