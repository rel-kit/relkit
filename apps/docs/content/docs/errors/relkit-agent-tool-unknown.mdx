**Agent called an unknown tool.**

## What happened

The model asked for a tool that the agent does not declare.

## What to do

List the tool in the agent's `tools`, or make the instructions name only the tools the agent has.

Reported by `@relkit/ai-sdk`, `relkit/agent-adapters`, `relkit/diagnostics`.
