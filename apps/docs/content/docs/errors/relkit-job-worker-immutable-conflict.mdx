**Job worker file already exists with different content.**

## What happened

A built job worker for this task version already exists with different code. Worker files for a version never change once written.

## What to do

Change the task `version` (or the job `buildId`) when you change its code, or delete the old `.relkit/build` folder if you are only rebuilding locally.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
