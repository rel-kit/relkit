**Inspector package is broken.**

## What happened

`@relkit/inspector` is installed, but its `package.json` does not declare the `relkit-inspector` command.

## What to do

Reinstall it with `bun add -d @relkit/inspector`, then run `relkit inspector` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.
