**Cache provider is missing an operation.**

## What happened

The configured cache provider does not implement the operation your code called.

## What to do

Configure a cache provider that implements this operation, or update the provider package to a version that does.

Reported by `@relkit/cache`, `@relkit/diagnostics`.
