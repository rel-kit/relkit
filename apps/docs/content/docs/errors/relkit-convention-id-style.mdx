**ID does not use the recommended style.**

## What happened

A definition ID is not lower case with parts separated by dots or hyphens, such as `orders.create`.

## What to do

Rename the ID to lower-case letters and numbers separated by dots or hyphens.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
