**Events could not be set up at startup.**

## What happened

When the app started, an event trigger or event was registered twice, pointed at an unknown function, or had no event provider configured.

## What to do

Run `relkit check` to find the event problem, check the events provider in your app config, then rebuild with `relkit build`.

Reported by `@relkit/diagnostics`, `@relkit/engine`.

See [all error codes](/docs/errors).
