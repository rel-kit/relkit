**Better Auth options are deprecated.**

## What happened

`defineBetterAuthService` received Better Auth options. RelKit still builds the Better Auth instance from them, but the options form is kept only as a transition.

## What to do

Write a Better Auth file with `betterAuth({ … })` and pass its instance as `defineBetterAuthService({ auth })`. Run `relkit migrate` to move the options into that file.

Reported by `@relkit/better-auth`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
