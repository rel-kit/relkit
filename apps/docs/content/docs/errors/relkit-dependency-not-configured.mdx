**Dependency is not configured.**

## What happened

A function used a managed dependency, such as a cache or database profile, that has no provider configured for this environment.

## What to do

Add the named profile to `relkit.config.ts` for this environment, or pass a replacement for it in tests.

Reported by `relkit/diagnostics`, `relkit/invocation`.

See [all error codes](/docs/errors).
