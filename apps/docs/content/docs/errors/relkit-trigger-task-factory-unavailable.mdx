**Trigger.dev SDK has no task function.**

## What happened

The installed `@trigger.dev/sdk` does not provide a function RelKit can use to create tasks.

## What to do

Install a version of `@trigger.dev/sdk` that includes the `v3` entry point, then restart.

Reported by `@relkit/trigger`, `relkit/diagnostics`.
