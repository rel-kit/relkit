**Reloaded app was built by a different RelKit version.**

## What happened

During `relkit dev`, the reloaded app's manifest was generated by a RelKit version this CLI does not support.

## What to do

Put all `@relkit/*` packages on the same version, run `bun install`, then restart `relkit dev`.

Reported by `@relkit/supervisor`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
