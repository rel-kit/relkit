**Observability query is from another version.**

## What happened

The tool that sent the query uses a query protocol or version that this RelKit version does not support.

## What to do

Update all `@relkit/*` packages and the CLI to the same version, then restart the app.

Reported by `@relkit/inspector`, `relkit/diagnostics`, `relkit/observability`.

See [all error codes](/docs/errors).
