**App sets both jobs and job.**

## What happened

`defineApp` sets both `jobs` and the older `job` option, or both `defaults.jobs` and `defaults.job`, so RelKit cannot tell which one to use.

## What to do

Keep `jobs` (or `defaults.jobs`) and remove the singular `job` option.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
