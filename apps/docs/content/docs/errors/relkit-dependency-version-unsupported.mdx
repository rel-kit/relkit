**Installed package version is not supported.**

## What happened

An integration you use needs a package version in a range that does not include the version installed in your project.

## What to do

Run the install command shown in the output to install a supported version.

Reported by `@relkit/diagnostics`, `@relkit/provider`.

See [all error codes](/docs/errors).
