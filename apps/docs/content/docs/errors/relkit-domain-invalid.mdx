**Domain is set up incorrectly.**

## What happened

A domain has more than one service, no definitions, members from another domain, or an unsupported database or Better Auth setup.

## What to do

Follow the message to fix the domain: one service per domain, members from that domain only, a Drizzle service when you use Better Auth, and default: true on one Drizzle service when there are several.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
