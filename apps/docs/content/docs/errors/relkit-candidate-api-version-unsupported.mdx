**Reloaded app uses an unsupported internal API.**

## What happened

During `relkit dev`, the reloaded app did not expose the internal health endpoint this CLI expects, usually because RelKit packages are on different versions.

## What to do

Put all `@relkit/*` packages on the same version, run `bun install`, then restart `relkit dev`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
