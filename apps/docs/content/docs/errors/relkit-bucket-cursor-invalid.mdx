**Bucket list cursor or limit is not valid.**

## What happened

A bucket list call received a cursor that RelKit did not issue, or a page limit that is not a positive integer.

## What to do

Pass the cursor from the previous list result unchanged, and use a positive whole number for the limit.

Reported by `@relkit/diagnostics`, `@relkit/providers-local`.

See [all error codes](/docs/errors).
