**Stream item belongs to an old attempt.**

## What happened

The provider saved a stream item for a different attempt of this run than the one now running.

## What to do

Make sure only the current attempt emits stream items. If the provider is custom, return the attempt's generation with each saved item.

Reported by `@relkit/diagnostics`, `@relkit/jobs`.

See [all error codes](/docs/errors).
