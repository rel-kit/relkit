**Event action request is not valid.**

## What happened

An event action request is not an object, or its reason is empty or not text.

## What to do

Send the request as an object, and leave out `reason` or give it non-empty text.

Reported by `@relkit/diagnostics`, `@relkit/providers-local`.

See [all error codes](/docs/errors).
