**Inngest event is missing RelKit data.**

## What happened

An Inngest function received an event without the RelKit data or input it needs.

## What to do

Submit jobs through RelKit instead of sending raw Inngest events to RelKit job functions.

Reported by `@relkit/inngest`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
