**Job watch read timed out.**

## What happened

Reading the next update for a watched job run took longer than the allowed time.

## What to do

Check the network connection and that the server is running, then start the watch again.

Reported by `@relkit/client`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
