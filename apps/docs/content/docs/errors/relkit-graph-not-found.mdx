**Application graph file not found.**

## What happened

RelKit could not find the graph file at the path in the message.

## What to do

`relkit check` writes the graph only when it passes: run it and fix the errors it reports (when the last check failed, the message names the first one), or pass the correct path to `relkit graph`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
