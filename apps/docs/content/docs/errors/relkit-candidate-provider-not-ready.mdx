**Reloaded app services are not ready.**

## What happened

During `relkit dev`, the reloaded app started but reported that a provider it depends on, such as a database, is not ready.

## What to do

Check the logs above for the provider that failed, make sure its local service is running with `relkit local status`, then save a file to reload.

Reported by `@relkit/supervisor`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
