**Service files are in the wrong place.**

## What happened

A service is in a location RelKit does not support, such as a nested or duplicate service, mixed layouts or an invalid service directory name.

## What to do

Move the file named in the message to `src/services/<service>/service.ts`, or run `relkit migrate layout` to preview the fix.

Reported by `relkit/contracts`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
