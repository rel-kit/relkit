**Previous app version could not be stopped.**

## What happened

During `relkit dev`, RelKit tried to stop the previous version of your app after a reload, but it was no longer tracking that version.

## What to do

Restart `relkit dev`. If this keeps happening, report this on the RelKit issue tracker with the full output.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
