**ID is used twice.**

## What happened

Two definitions in the app have the same ID, so RelKit cannot tell them apart.

## What to do

Rename one of them, or give it an explicit `id` if the ID was taken from the file or export name.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
