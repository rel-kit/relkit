**Event profile is not configured.**

## What happened

An event was published through a profile that is not configured for this environment.

## What to do

Add the event profile to `relkit.config.ts`, or point the event at a profile that exists.

Reported by `relkit/diagnostics`, `relkit/events`.

See [all error codes](/docs/errors).
