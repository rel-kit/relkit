**Job streams are not available.**

## What happened

The job's provider does not support named streams, or it returned an invalid stream.

## What to do

Use a job provider that supports streams, or read the run's status and result instead of streaming.

Reported by `relkit/diagnostics`, `relkit/runtime-hono`.

See [all error codes](/docs/errors).
