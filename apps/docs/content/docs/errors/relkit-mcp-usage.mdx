**Invalid relkit mcp arguments.**

## What happened

`relkit mcp` received an option it does not accept or an option without a value.

## What to do

Run `relkit mcp --help` for the accepted options, then run the command again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
