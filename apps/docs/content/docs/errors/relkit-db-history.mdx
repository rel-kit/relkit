**Migration history is missing or incompatible.**

## What happened

`relkit db migrate` found no migration files, an empty history or one written for a different Drizzle version.

## What to do

Run `bun run db:generate`, review the generated migrations for your installed Drizzle versions, then migrate again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
