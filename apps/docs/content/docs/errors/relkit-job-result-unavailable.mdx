**Job result is not available.**

## What happened

The run has no result you can read. It may still be running, or its result expired, was redacted, or came from an incompatible job version.

## What to do

Check the run with `relkit jobs runs get`. If it is still running, wait longer. Otherwise trigger the job again to get a new result.

Reported by `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
