**Invalid relkit local arguments.**

## What happened

`relkit local` received an unknown subcommand or option, an option without its value, or `reset` without confirmation.

## What to do

Run `relkit local up|status|stop|reset [options]`, and pass `--yes` to `reset` when not running interactively.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
