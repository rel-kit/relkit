**Profile name is invalid.**

## What happened

A `profile` or `service` value is not a valid profile ID.

## What to do

Use a profile ID made of letters and numbers, optionally joined by dots, hyphens or underscores, that matches a profile in your app config.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
