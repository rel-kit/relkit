**Job profile option is deprecated.**

## What happened

A job uses the `profile` option, which has been renamed to `service`. Setting both is an error.

## What to do

Rename `profile` to `service` in `defineJob`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`, `@relkit/jobs`.

See [all error codes](/docs/errors).
