**Stream item cannot be sent as JSON.**

## What happened

A stream item could not be encoded as JSON.

## What to do

Send only JSON values in streams. Convert dates, class instances and other values to plain data first.

Reported by `relkit/diagnostics`, `relkit/invocation`.

See [all error codes](/docs/errors).
