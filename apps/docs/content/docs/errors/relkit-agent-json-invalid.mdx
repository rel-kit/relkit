**Agent value is not plain JSON.**

## What happened

A value passed into or out of the agent, such as its input, output or a tool result, could not be converted to JSON.

## What to do

Use only JSON values. Convert dates, class instances, functions and other values to plain data first.

Reported by `@relkit/langchain`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
