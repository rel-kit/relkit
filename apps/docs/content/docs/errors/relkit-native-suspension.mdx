**Execution paused by the provider.**

## What happened

The job or workflow provider paused execution so it can resume later. This is a control signal, not a failure.

## What to do

No action is needed. If you see it as an error, make sure your code does not catch and rethrow it.

Reported by `@relkit/diagnostics`, `@relkit/invocation`.

See [all error codes](/docs/errors).
