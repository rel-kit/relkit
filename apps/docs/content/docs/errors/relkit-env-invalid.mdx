**Environment module has no definition.**

## What happened

Your environment file loaded, but it does not export an environment definition RelKit can read.

## What to do

Export the environment definition from `src/platform/env.ts`, then run the command again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
