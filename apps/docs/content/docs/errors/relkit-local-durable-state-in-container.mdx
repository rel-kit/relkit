**Production image refused the local provider for durable work.**

## What happened

The server started inside the image that `relkit build` emits, which sets `RELKIT_DURABLE_STATE=external`, and a jobs or events profile it uses selects the local filesystem provider. The image keeps no durable state on its own disk, so provider startup fails and `/healthz` stays unready.

## What to do

Use the durable Postgres backend from `@relkit/postgres` (`relkit add jobs --provider postgres`, `relkit add events --provider postgres`). For a single instance with a persistent volume mounted at `/app/.relkit/state`, set `RELKIT_ALLOW_LOCAL_DURABLE_STATE=1` instead.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
