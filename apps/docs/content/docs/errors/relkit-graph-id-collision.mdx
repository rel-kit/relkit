**Two parts of the app share an ID.**

## What happened

Two different kinds of things in your app, such as a function and a job, end up with the same ID.

## What to do

Rename one of them so every ID in the app is unique, then run `relkit check`.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
