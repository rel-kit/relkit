**Model is not available.**

## What happened

An agent uses a model that its provider does not offer or does not support for this use.

## What to do

Pick a model the provider offers with the features your agent needs, then restart the app.

Reported by `@relkit/diagnostics`, `@relkit/engine`.

See [all error codes](/docs/errors).
