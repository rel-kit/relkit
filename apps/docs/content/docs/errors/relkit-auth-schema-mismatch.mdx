**The database schema does not match the installed Better Auth release.**

## What happened

Better Auth checks the Drizzle schema when it starts and found a missing table or column, or a required column it never writes, so every sign-up and sign-in would fail. A project created before Better Auth 1.7.7 declares a required `account.issuer` column that Better Auth 1.7.3 and later never write.

## What to do

Change the schema as the message lists: for `account.issuer`, run `relkit migrate --write` or remove the column and its index by hand (see /docs/modules/auth/better-auth#remove-the-account-issuer-column). Then run `db:generate` and `db:migrate`.

Reported by `@relkit/better-auth`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
