**Middleware is not defined.**

## What happened

A route refers to a middleware that is not defined in your app.

## What to do

Define the middleware with `defineMiddleware`, or fix the reference so it points at one that exists.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
