**Invalid relkit graph arguments.**

## What happened

`relkit graph` received an unknown subcommand or option, an option without its value, or the wrong number of paths.

## What to do

Run `relkit graph print|check|diff [paths]`, giving two paths to `diff`, or see `relkit graph --help`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
