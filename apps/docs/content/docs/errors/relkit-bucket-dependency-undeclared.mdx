**Bucket is not declared on this function.**

## What happened

A function used a bucket that is not listed in its dependencies.

## What to do

Add the bucket to the function's `dependencies`, for example `dependencies: { buckets: { assets } }`.

Reported by `@relkit/buckets`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
