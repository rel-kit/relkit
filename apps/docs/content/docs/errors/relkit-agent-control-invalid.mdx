**Agent is missing the approve control.**

## What happened

An agent exposed to clients uses a tool that needs approval, but the agent does not declare the `approve` control.

## What to do

Add `"approve"` to the agent's client controls, or set the tool's `approval` to `"never"` if it does not need approval.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
