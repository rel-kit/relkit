**SQLite database on Cloudflare Workers.**

## What happened

`relkit check` found a wrangler configuration in the project and a Drizzle service with the SQLite dialect. SQLite keeps the database in a local file, and a Worker has no filesystem.

## What to do

Use a Postgres database the Worker can reach with the `pg` Drizzle dialect, for example through Cloudflare Hyperdrive, or deploy the app to a container target such as Railway.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
