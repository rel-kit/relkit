**Files to migrate have uncommitted changes.**

## What happened

A tracked file that `relkit migrate --write` needs to change has uncommitted changes in Git.

## What to do

Commit or stash your changes, then run `relkit migrate --write` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
