**Application graph version is not supported.**

## What happened

The application graph was generated in a format version the deployment tools do not support.

## What to do

Put all `@relkit/*` packages on the same version, run `relkit check`, then deploy again.

Reported by `relkit/deploy`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
