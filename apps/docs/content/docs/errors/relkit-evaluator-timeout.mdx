**Loading source files timed out.**

## What happened

Loading your source files took too long, so RelKit stopped. A slow or endless top-level `await` is a common cause.

## What to do

Remove long-running work, such as awaiting a network call, from the top level of your modules, then run `relkit check` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
