**Project creation failed.**

## What happened

Generating the new project stopped because of an error, and RelKit removed the files it had written.

## What to do

Read the message above, fix the cause (often disk space, permissions or network), then run the create command again.

Reported by `create-relkit`, `relkit/diagnostics`.
