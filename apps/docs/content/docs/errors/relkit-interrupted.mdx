**Command was interrupted.**

## What happened

The command stopped because it received an interrupt signal, such as Ctrl-C, SIGTERM or SIGHUP.

## What to do

Run the command again when you are ready. If you did not stop it, check what sent the signal.

Reported by `@relkit/cli`, `create-relkit`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
