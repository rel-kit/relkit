**Rollback kept a later edit.**

## What happened

A file changed by `relkit migrate` was edited afterwards, so the rollback changed nothing rather than overwrite your edit.

## What to do

Undo the later edit, or restore the files with Git, then run the rollback again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
