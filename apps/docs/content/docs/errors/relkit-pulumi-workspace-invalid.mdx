**Pulumi workspace settings are invalid.**

## What happened

The Pulumi settings for this deployment are invalid, such as an empty work directory, an unsupported backend URL or a stack name with unsupported characters.

## What to do

Fix the setting named in the message, for example pass `--backend cloud`, `local` or an `s3://`, `azblob://` or `gs://` URL, then deploy again.

Reported by `@relkit/deploy-pulumi`, `relkit/diagnostics`.
