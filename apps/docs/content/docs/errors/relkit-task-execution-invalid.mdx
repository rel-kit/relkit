**Task run does not match the build.**

## What happened

A queued task run does not match the task, build or input that the running app has registered, so RelKit refused to run it.

## What to do

Run `relkit build` and deploy all of its output together. If it persists, report this on the RelKit issue tracker with the full output.

Reported by `@relkit/diagnostics`, `@relkit/engine`.

See [all error codes](/docs/errors).
