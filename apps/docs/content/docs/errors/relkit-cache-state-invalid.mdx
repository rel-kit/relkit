**Local cache snapshot is not usable.**

## What happened

The local cache provider could not read or write its saved snapshot, or the snapshot data is malformed.

## What to do

Stop the app and delete the cache folder under `.relkit/state`, then start again. This clears cached values.

Reported by `@relkit/diagnostics`, `@relkit/providers-local`.

See [all error codes](/docs/errors).
