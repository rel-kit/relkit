**Production build uses the local provider for durable work.**

## What happened

`relkit build` found jobs, schedules or events whose profile uses the local filesystem provider, which keeps their state in `.relkit/state` on one machine. A production instance loses that state on redeploy and does not share it with other instances.

## What to do

Select the durable Postgres backend from `@relkit/postgres` for the profile, with `relkit add jobs --provider postgres` or `relkit add events --provider postgres`. The build still succeeds; this is a warning.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
