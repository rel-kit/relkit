**Request transform is missing from the build.**

## What happened

A request transform in the app graph has no code RelKit can run, or it is missing from the built manifest.

## What to do

Make sure the transform is exported from its file, then run `relkit build` again and deploy all of its output.

Reported by `@relkit/compiler`, `@relkit/diagnostics`, `@relkit/runtime-hono`.

See [all error codes](/docs/errors).
