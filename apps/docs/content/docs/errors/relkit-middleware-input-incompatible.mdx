**Middleware input does not match the route.**

## What happened

A middleware expects input that the route it runs on does not provide.

## What to do

Change the middleware's input schema or the route so they match, then run `relkit check`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
