**Trigger.dev run belongs to another scope.**

## What happened

A Trigger.dev run was read from a scope other than the one it was created in.

## What to do

Read the run with the same scope used to submit it. Check how your app resolves the job scope for the caller.

Reported by `@relkit/trigger`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
