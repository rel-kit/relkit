**Two routes use the same path.**

## What happened

Two routes answer the same method and path, or a route name clashes with the generated client's `jobs` namespace.

## What to do

Change the path or method of one route, or rename the route that clashes with `jobs`.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
