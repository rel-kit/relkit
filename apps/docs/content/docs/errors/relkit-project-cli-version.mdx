**The project's CLI version differs from relkit.**

## What happened

The `relkit` command and the project's `@relkit/cli` have different versions. Every RelKit package is released with the same version.

## What to do

Install matching versions, for example `bun add relkit@<version>` and `bun add -d @relkit/cli@<version>` with the same version, then run the command again.

Reported by `relkit/diagnostics`.

See [all error codes](/docs/errors).
