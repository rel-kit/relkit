**No integration for a provider.**

## What happened

The app needs a provider that no installed integration package can create.

## What to do

Install the integration package for the provider named in the error, then run `relkit build` again.

Reported by `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
