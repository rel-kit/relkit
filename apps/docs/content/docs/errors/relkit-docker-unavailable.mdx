**Docker is not available.**

## What happened

RelKit could not run Docker, so local services that need it cannot start.

## What to do

Install Docker and start the Docker daemon, then check it works with `docker info`.

Reported by `@relkit/diagnostics`, `@relkit/docker`.

See [all error codes](/docs/errors).
