**Job input does not match its target.**

## What happened

A job's input schema does not fit the input of the function or task it runs.

## What to do

Change the job input so it matches the target's input schema, then run `relkit check`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
