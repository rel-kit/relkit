**Job does not point at a task.**

## What happened

A job targets a function or something other than a task. New jobs must run a task.

## What to do

Set the job's `task` to a task made with `defineTask` and remove `target`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
