**Agent run timed out.**

## What happened

The agent did not finish before its time limit or deadline.

## What to do

Raise the agent's `timeoutMs` limit, or reduce the work it has to do, for example with fewer steps or faster tools.

Reported by `@relkit/diagnostics`, `@relkit/langchain`.

See [all error codes](/docs/errors).
