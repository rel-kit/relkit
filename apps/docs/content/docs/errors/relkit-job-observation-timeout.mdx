**Reading job status timed out.**

## What happened

RelKit asked the job provider for the run's status, but the provider did not answer in time.

## What to do

Check that the job provider is running and reachable, then try again. Raise the timeout if the provider is slow.

Reported by `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
