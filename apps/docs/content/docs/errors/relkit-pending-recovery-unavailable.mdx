**Pending job cannot be retried.**

## What happened

A job submission with an unknown result cannot be retried because its retry window with the same key has closed.

## What to do

Check whether the job was created before submitting it again with a new operation ID.

Reported by `@relkit/client`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
