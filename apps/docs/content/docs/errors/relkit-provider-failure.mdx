**Provider operation failed.**

## What happened

An external provider, such as a database, cache or queue, returned an error while running an operation.

## What to do

Check the error's cause and the provider's logs. Make sure the provider is running and its connection settings are correct.

Reported by `relkit/diagnostics`, `relkit/invocation`.

See [all error codes](/docs/errors).
