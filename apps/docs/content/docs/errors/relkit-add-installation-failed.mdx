**Dependency installation failed after relkit add.**

## What happened

`relkit add` updated your project, but installing the new dependencies failed.

## What to do

Install the project's dependencies again with your package manager to see the full error, fix it (often network or registry access), then run `relkit add` again.

Reported by `create-relkit`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
