**Dependency installation failed after relkit add.**

## What happened

`relkit add` updated your project, but installing the new dependencies with `bun install` failed.

## What to do

Run `bun install` in the project to see the full error, fix it (often network or registry access), then run `relkit add` again.

Reported by `@relkit/diagnostics`, `create-relkit`.

See [all error codes](/docs/errors).
