**Route export is not an HTTP method.**

## What happened

A route file uses a default export or an unsupported method, or a Better Auth route does not use `ALL`.

## What to do

Export each route as a named HTTP method, such as `export const GET = defineRoute(...)`. Use `ALL` only for the Better Auth route.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
