**Local project lock is damaged.**

## What happened

The lock file RelKit uses for this project's local services is missing data or is not valid.

## What to do

Stop local services with `relkit local stop`, then run `relkit local reset` if the problem stays.

Reported by `@relkit/diagnostics`, `@relkit/local`.

See [all error codes](/docs/errors).
