**Local services are in use by another session.**

## What happened

Another `relkit dev` session is already using this project's local services.

## What to do

Stop that session with Ctrl-C (its process ID is in the message), then try again.

Reported by `@relkit/cli`, `@relkit/diagnostics`, `@relkit/local`.

See [all error codes](/docs/errors).
