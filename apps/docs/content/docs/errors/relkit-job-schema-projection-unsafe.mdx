**Job or task schema cannot be stored safely.**

## What happened

A job overrides its task's input or output schema, or a task's input schema transforms data, so RelKit cannot store job input faithfully.

## What to do

Remove input and output overrides from the job. If the task input transforms data, add an `inputWire` schema that keeps values unchanged.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
