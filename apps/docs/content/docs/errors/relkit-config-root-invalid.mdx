**Project folder or config is invalid.**

## What happened

RelKit could not use the project folder, or `relkit.config.ts` does not export a plain object.

## What to do

Run the command from your project folder and make sure `relkit.config.ts` default-exports a plain object.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
