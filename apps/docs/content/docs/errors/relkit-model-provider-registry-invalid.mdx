**Agent has no active model provider.**

## What happened

An agent uses a model profile that has no model provider running.

## What to do

Configure a model provider for the agent's profile in your app config, then restart the app.

Reported by `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
