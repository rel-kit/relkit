**Agent timeout or deadline is invalid.**

## What happened

The `timeoutMs` or `deadlineMs` passed to the agent run is not a finite, non-negative whole number.

## What to do

Pass `timeoutMs` as a non-negative whole number of milliseconds, and `deadlineMs` as a finite timestamp.

Reported by `@relkit/langchain`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
