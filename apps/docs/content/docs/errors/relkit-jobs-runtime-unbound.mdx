**Jobs runtime is not available here.**

## What happened

Your code used a job control, such as waiting for a result or managing a schedule, outside a request or task that RelKit is running.

## What to do

Call job controls from inside a function or task handler, not at module load time or from a standalone script.

Reported by `@relkit/diagnostics`, `@relkit/jobs`.
