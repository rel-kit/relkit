**Inspector cannot reach the runtime.**

## What happened

The Inspector endpoint could not read data from the running app.

## What to do

Make sure the app is running and finished starting, then refresh the Inspector. Check the app's logs for startup errors.

Reported by `@relkit/diagnostics`, `@relkit/inspector-api`, `@relkit/runtime-hono`.

See [all error codes](/docs/errors).
