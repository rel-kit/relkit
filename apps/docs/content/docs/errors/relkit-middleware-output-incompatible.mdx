**Middleware output does not match the route.**

## What happened

A middleware returns output that the route or its function cannot accept.

## What to do

Change the middleware's output schema or the route so they match, then run `relkit check`.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
