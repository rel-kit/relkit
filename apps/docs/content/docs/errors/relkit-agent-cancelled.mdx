**Agent run was cancelled.**

## What happened

The agent stopped because its caller cancelled the run or its abort signal fired.

## What to do

If you did not mean to cancel it, check where the abort signal comes from (a closed request, a client disconnect) and run the agent again.

Reported by `@relkit/diagnostics`, `@relkit/langchain`.

See [all error codes](/docs/errors).
