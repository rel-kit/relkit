**Tool call was denied.**

## What happened

A tool call that needs approval was denied, so the tool did not run.

## What to do

Nothing is broken. If the call should have run, approve it the next time it is requested, or change the tool's approval policy.

Reported by `relkit/agents`, `relkit/diagnostics`, `relkit/functions`.
