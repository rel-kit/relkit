**Invalid relkit arguments.**

## What happened

The `relkit` command line could not be parsed, for example `--help` and `--version` were both passed or an option was malformed.

## What to do

Run `relkit --help` to see the commands and options, then run the command again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
