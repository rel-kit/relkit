**App graph is not available.**

## What happened

The Inspector could not load the app graph from the running app.

## What to do

Make sure the app finished starting, then refresh the Inspector. Run `relkit build` again if the build output is missing.

Reported by `@relkit/diagnostics`, `@relkit/inspector-api`.
