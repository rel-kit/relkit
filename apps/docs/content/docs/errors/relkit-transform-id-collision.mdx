**Transform ID is used twice.**

## What happened

A request transform has the same ID as another definition in your app.

## What to do

Rename the transform, or give it an explicit `id` if the ID was taken from the file or export name.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
