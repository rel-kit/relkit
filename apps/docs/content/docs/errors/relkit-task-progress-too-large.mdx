**Progress update is too large.**

## What happened

A task emitted a progress value larger than its byte limit, so RelKit did not store it.

## What to do

Send a smaller progress value, such as counts or an ID, and keep large data in your own storage.

Reported by `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
