**Graph hash does not match.**

## What happened

The graph's calculated hash differs from the one you passed with `--hash`.

## What to do

Run `relkit check` to regenerate the graph, or update the expected hash if the change is intended.

Reported by `@relkit/cli`, `@relkit/diagnostics`.
