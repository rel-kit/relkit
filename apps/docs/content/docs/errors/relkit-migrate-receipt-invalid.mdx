**Migration record is invalid.**

## What happened

The migration record passed to `relkit migrate --rollback` does not belong to this project, is not a code migration record, or was changed.

## What to do

Pass the record path printed by the `relkit migrate --write` you want to undo. Layout records roll back with `relkit migrate layout --rollback`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
