**Tool target does not match.**

## What happened

A tool's target is not a function, or the tool's schemas differ from the function it calls.

## What to do

Point the tool at a function made with `defineFunction` and use the same input and output schemas.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
