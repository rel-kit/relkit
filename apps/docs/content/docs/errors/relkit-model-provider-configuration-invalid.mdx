**Model provider settings are invalid.**

## What happened

The model provider settings in your app config are missing a value or have the wrong shape.

## What to do

Set a default provider and default model, and list each provider you use in the app's model settings.

Reported by `@relkit/compiler`, `relkit/agents`, `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
