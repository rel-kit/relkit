**Tool call failed.**

## What happened

A tool the agent called failed with an error that is not one of the tool's declared errors.

## What to do

Check the app logs for the tool's error and fix it, or declare the error on the tool so the agent can handle it.

Reported by `@relkit/diagnostics`, `@relkit/langchain`.

See [all error codes](/docs/errors).
