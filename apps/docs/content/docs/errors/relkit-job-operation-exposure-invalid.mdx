**Job client settings are invalid.**

## What happened

A job's `client` option is not an object, lists no operations, or names an operation or field that is not supported.

## What to do

Set `client.operations` to a non-empty list of supported operations and use only supported `client.fields`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
