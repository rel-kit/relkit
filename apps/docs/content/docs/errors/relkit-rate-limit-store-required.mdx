**Rate limit needs a shared store.**

## What happened

A route has a rate limit with no `store`. Production builds need a shared cache so limits work across instances.

## What to do

Set `rateLimit.store` to a shared cache defined with `defineCache`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
