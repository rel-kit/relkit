**Agent value is too large.**

## What happened

A value passed into or out of the agent was larger than its byte limit.

## What to do

Send less data to the agent or ask for a shorter answer, or raise `maxInputBytes` or `maxOutputBytes`.

Reported by `@relkit/langchain`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
