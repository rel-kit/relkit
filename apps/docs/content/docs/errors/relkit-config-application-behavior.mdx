**Tooling config has an invalid value.**

## What happened

A setting in `relkit.config.ts` has the wrong type, or the tooling config holds functions, getters or other code where only plain data is allowed.

## What to do

Use plain values (strings, numbers, booleans, arrays and objects) for the setting named in the error, and keep app logic in `src/`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
