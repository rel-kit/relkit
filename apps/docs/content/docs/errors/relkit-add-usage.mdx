**Invalid relkit add arguments.**

## What happened

`relkit add` received an unknown kind, an invalid name, conflicting options or an option without its value.

## What to do

Run `relkit add --help` to see the accepted kinds and options, then run the command again.

Reported by `create-relkit`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
