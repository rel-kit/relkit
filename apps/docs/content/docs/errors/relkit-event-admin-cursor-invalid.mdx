**Event query cursor is not valid.**

## What happened

An event query received a cursor that RelKit did not issue.

## What to do

Pass the cursor from the previous page unchanged, or start again without a cursor.

Reported by `@relkit/diagnostics`, `@relkit/providers-local`.
