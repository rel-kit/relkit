**Middleware does not match the build.**

## What happened

A middleware in the built manifest does not match the middleware in the app graph.

## What to do

Run `relkit build` again so the manifest and the app match, then restart the server.

Reported by `relkit/diagnostics`, `relkit/runtime-hono`.

See [all error codes](/docs/errors).
