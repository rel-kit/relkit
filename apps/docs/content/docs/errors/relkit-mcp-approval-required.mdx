**MCP tool needs approval.**

## What happened

An MCP client called a tool whose `approval` policy requires a person to approve each call. The `/mcp` endpoint cannot ask for approval, so the tool did not run.

## What to do

Run the tool from an agent, which pauses for approval and lets you approve the call in the Inspector's tool page. If the tool is safe to run without review, set its `approval` to `"never"`.

Reported by `relkit/diagnostics`, `relkit/runtime-hono`.

See [all error codes](/docs/errors).
