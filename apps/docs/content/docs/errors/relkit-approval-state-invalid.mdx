**Approval cannot change to this state.**

## What happened

An approval record is malformed, or it was asked to move to a state it cannot reach, such as approving one that is already settled.

## What to do

Load the latest approval before acting on it, and only approve or deny approvals that are still pending.

Reported by `relkit/agents`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
