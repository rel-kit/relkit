**Agent size limit is invalid.**

## What happened

The agent's `maxInputBytes` or `maxOutputBytes` is not a positive whole number, or it is above the model's limit.

## What to do

Set `maxInputBytes` and `maxOutputBytes` to positive whole numbers no larger than the model allows, or remove them to use the defaults.

Reported by `@relkit/diagnostics`, `@relkit/langchain`.

See [all error codes](/docs/errors).
