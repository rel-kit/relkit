**Local event log is damaged.**

## What happened

The local event provider found a record in its saved event log that it cannot read.

## What to do

Stop the app and delete the events folder under `.relkit/state`, then start again. This clears local events.

Reported by `@relkit/diagnostics`, `@relkit/providers-local`.

See [all error codes](/docs/errors).
