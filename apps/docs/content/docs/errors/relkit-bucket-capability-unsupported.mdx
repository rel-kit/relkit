**Bucket provider does not support this operation.**

## What happened

Your code called a bucket operation, such as a signed read or write URL, that the selected bucket provider does not support.

## What to do

Use a bucket provider that supports this capability, or read and write the object through the bucket client instead of a signed URL.

Reported by `relkit/buckets`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
