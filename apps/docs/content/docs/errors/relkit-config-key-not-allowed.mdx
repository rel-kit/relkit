**Unknown tooling config setting.**

## What happened

`relkit.config.ts` has a setting RelKit does not recognize, at the top level or inside `server`, `inspector` or `deployment`.

## What to do

Remove or rename the setting named in the error, checking for typos.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
