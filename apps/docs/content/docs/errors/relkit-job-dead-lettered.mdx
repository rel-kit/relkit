**Job run moved to the dead-letter state.**

## What happened

A job run failed on its last permitted attempt, or failed with an error that forbids retries, so the backend stopped retrying it and kept it as a failed run.

## What to do

Read the run's error, fix the cause, then call `retry` on the run to start a new run from the same input.

Reported by `@relkit/postgres`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
