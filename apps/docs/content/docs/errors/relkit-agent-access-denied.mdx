**Agent tool call was refused.**

## What happened

The engine's access check refused a tool the agent tried to call.

## What to do

Check the access rule of the function behind the tool, or call the agent as a caller that the rule allows.

Reported by `@relkit/testing`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
