**Stream cursor is ahead of the stream.**

## What happened

The stream cursor is newer than any record RelKit has, often because it came from an earlier run of the app.

## What to do

Reconnect without a cursor to follow the stream from now.

Reported by `@relkit/diagnostics`, `@relkit/observability`.

See [all error codes](/docs/errors).
