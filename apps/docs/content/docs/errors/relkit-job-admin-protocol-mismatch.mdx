**Job tools are on different versions.**

## What happened

The tool that sent the job request uses a protocol version that the local provider does not support.

## What to do

Update all `@relkit/*` packages and the CLI to the same version, then restart the app.

Reported by `@relkit/diagnostics`, `@relkit/providers-local`.

See [all error codes](/docs/errors).
