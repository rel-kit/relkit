**The command was run outside a project.**

## What happened

The `relkit` command looked for a `package.json` in the current folder and its parents and found none.

## What to do

Run the command from your project folder, pass `--project-root <folder>`, or create a project with `relkit create <name>`.

Reported by `relkit/diagnostics`.

See [all error codes](/docs/errors).
