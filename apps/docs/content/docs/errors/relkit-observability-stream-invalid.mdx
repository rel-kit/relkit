**Observability stream request is not valid.**

## What happened

A live stream request has a bad cursor, conflicting cursors or a size limit out of range.

## What to do

Check the message for the field that failed. Send one cursor taken unchanged from the stream, and use positive limits.

Reported by `@relkit/inspector-api`, `relkit/diagnostics`, `relkit/observability`.

See [all error codes](/docs/errors).
