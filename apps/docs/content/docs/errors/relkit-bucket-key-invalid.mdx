**Bucket key is not valid.**

## What happened

An object key or prefix is empty, longer than 4096 bytes, absolute, contains `\`, `.` or `..` segments, or starts with a reserved prefix such as `.relkit`.

## What to do

Use a relative key made of non-empty segments separated by `/`, such as `avatars/123.png`.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
