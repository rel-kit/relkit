**MCP server package is not installed.**

## What happened

`relkit mcp` needs the `@modelcontextprotocol/server` package to speak the Model Context Protocol, and the project does not have it installed. The package is optional so that projects that never run `relkit mcp` do not carry it.

## What to do

Add it to the project's development dependencies, for example `bun add -d @modelcontextprotocol/server`, then start `relkit mcp` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
