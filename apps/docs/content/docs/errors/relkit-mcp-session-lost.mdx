**Development session stopped answering.**

## What happened

A `relkit mcp` tool could not reach the development session it connected to, often because `relkit dev` stopped or restarted.

## What to do

Make sure `relkit dev` is running, then restart `relkit mcp` so it connects to the current session.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
