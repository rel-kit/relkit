**Job failed with an undeclared error.**

## What happened

The job failed with an error that is not in its declared `errors`, so RelKit shows a generic failure instead of the details.

## What to do

Check the job's logs for the real error. To show it to callers, add that error to the job's `errors` and throw it from the handler.

Reported by `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
