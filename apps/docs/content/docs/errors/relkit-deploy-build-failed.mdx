**Build failed before deployment.**

## What happened

`relkit deploy` builds your app first, and that build failed.

## What to do

Run `relkit build` to see the errors, fix them, then run `relkit deploy` again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
