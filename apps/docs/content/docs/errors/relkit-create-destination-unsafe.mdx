**Destination path is unsafe.**

## What happened

The destination is a symbolic link, the current directory, a filesystem root or another broad directory that RelKit will not write a project into.

## What to do

Choose a new, specific directory for the project, such as `./my-app`.

Reported by `create-relkit`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
