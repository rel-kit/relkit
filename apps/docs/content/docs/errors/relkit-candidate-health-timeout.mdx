**Reloaded app did not become healthy in time.**

## What happened

During `relkit dev`, the reloaded app did not answer its health checks before the time limit, so RelKit kept the previous version running.

## What to do

Check the logs above for slow or failing startup code, such as a database connection, fix it and save a file to reload.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
