**Invalid relkit migrate arguments.**

## What happened

`relkit migrate` received an unknown option, an option without its value, or both `--write` and `--rollback`.

## What to do

Run `relkit migrate` to preview, then `--write` to apply or `--rollback <record>` to undo, not both.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
