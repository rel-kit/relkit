**Docker container is unhealthy.**

## What happened

A local service container started but its health check reported it as unhealthy.

## What to do

Run `docker logs` for the container to see why it is failing, fix its settings, then start local services again.

Reported by `@relkit/diagnostics`, `@relkit/docker`.
