**Task paused for a durable sleep.**

## What happened

The local job provider pauses a task during `sleep` or `sleepUntil` by throwing this marker. You see it only when your code catches it.

## What to do

Rethrow errors you do not handle in `try`/`catch` blocks around `sleep` and `sleepUntil` so RelKit can resume the task later.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
