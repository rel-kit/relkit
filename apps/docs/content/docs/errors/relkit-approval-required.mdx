**Tool call needs approval.**

## What happened

The agent tried to call a tool that requires approval, so the call is paused until someone approves or denies it.

## What to do

Approve or deny the pending call, for example from the Inspector. Remove the approval requirement from the tool if it should run without review.

Reported by `@relkit/langchain`, `relkit/agents`, `relkit/diagnostics`, `relkit/functions`.
