**Legacy jobs are not enabled.**

## What happened

Your app defines a job in the older function-target style, which is turned off by default.

## What to do

Move the job to the current job definition style, or set `defineApp({ compatibility: { legacyJobs: true } })` while you migrate.

Reported by `@relkit/cli`, `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
