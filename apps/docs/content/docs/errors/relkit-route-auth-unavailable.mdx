**A route requires a session, but the app has no Better Auth route.**

## What happened

A route sets `auth: "required"`, and the application does not mount a Better Auth handler, so no request could ever have a session. At run time such a route answers every request with 401.

## What to do

Mount Better Auth with an `ALL` route whose handler is your Better Auth service's handler, or remove `auth: "required"` from the route.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
