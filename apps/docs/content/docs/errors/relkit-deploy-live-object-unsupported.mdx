**Graph contains a live object.**

## What happened

The application graph contains a live runtime object, such as a client or function, which cannot be part of a deployment plan.

## What to do

Declare deployment settings as plain values in your app definition, then run `relkit check` and deploy again.

Reported by `relkit/deploy`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
