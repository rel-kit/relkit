**Model selector is invalid.**

## What happened

An agent's `model` value is not a valid model selector.

## What to do

Use a selector in the form `"provider:model"`, or a provider name that has a default model.

Reported by `@relkit/agents`, `@relkit/compiler`, `@relkit/diagnostics`, `@relkit/engine`.

See [all error codes](/docs/errors).
