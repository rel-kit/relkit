**Event query is not valid.**

## What happened

An event query has a limit that is not a positive integer, an event version below 1, or an unknown state filter.

## What to do

Use a positive whole number for the limit and the version, and filter by `available`, `leased`, `delayed`, `completed` or `dead-lettered`.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
