**Task input is too large.**

## What happened

The task input is larger than its byte limit, which is 1 MiB of JSON by default.

## What to do

Send a smaller input, such as an ID, and keep large data in your own storage or a bucket.

Reported by `@relkit/diagnostics`, `@relkit/jobs`.

See [all error codes](/docs/errors).
