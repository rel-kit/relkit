**Reloaded app reported the wrong version.**

## What happened

During `relkit dev`, the health check answered for a different version of your app than the one RelKit started.

## What to do

Make sure no other process is using the same port, then restart `relkit dev`.

Reported by `@relkit/diagnostics`, `@relkit/supervisor`.

See [all error codes](/docs/errors).
