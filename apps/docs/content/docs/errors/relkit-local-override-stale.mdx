**Local provider settings are out of date.**

## What happened

The saved local provider settings were made for a different build of the app.

## What to do

Restart local services with `relkit dev` so the settings are written for the current build.

Reported by `@relkit/local`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
