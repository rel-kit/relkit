**Drizzle is not installed.**

## What happened

`relkit db migrate` needs `drizzle-orm` and `drizzle-kit` installed in your app.

## What to do

Run `bun add drizzle-orm` and `bun add -d drizzle-kit` in the app, then migrate again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
