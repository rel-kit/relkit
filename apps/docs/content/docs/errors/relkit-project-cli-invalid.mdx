**The installed CLI package is damaged.**

## What happened

The `relkit` command found `@relkit/cli` in the project, but its `package.json` names no `relkit` command or points outside the package.

## What to do

Reinstall the CLI with `bun add -d @relkit/cli`, then run the command again.

Reported by `relkit/diagnostics`.

See [all error codes](/docs/errors).
