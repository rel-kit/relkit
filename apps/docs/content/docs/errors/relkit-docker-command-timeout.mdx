**Docker command timed out.**

## What happened

A Docker command run by RelKit did not finish in time.

## What to do

Make sure Docker is responsive (`docker info`) and that image pulls are not stuck, then try again.

Reported by `@relkit/diagnostics`, `@relkit/docker`.
