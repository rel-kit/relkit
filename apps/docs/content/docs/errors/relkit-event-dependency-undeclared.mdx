**Event is not declared on this function.**

## What happened

A function published an event that is not listed in its declared event dependencies.

## What to do

Add the event to the function's declared events, then run `relkit build` again.

Reported by `relkit/diagnostics`, `relkit/events`.

See [all error codes](/docs/errors).
