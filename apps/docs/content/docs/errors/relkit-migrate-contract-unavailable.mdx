**The client contract could not be read.**

## What happened

The file passed to `relkit migrate --contract` does not exist or is not a client contract, so hook keys could not be named.

## What to do

Run `relkit check` in the backend, then pass its `.relkit/generated/client-contract.json`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
