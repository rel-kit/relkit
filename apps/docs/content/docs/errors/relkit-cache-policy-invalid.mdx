**Cache operation breaks the cache policy.**

## What happened

A cache setting or write does not match the cache policy. For example, a TTL is above `maxTtlMs`, a value is larger than `maxBytes`, or an increment overflowed.

## What to do

Check the message for the rule that failed, then change the value or TTL, or update the limits in the cache definition.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
