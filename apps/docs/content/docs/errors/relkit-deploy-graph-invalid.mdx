**Application graph cannot be deployed.**

## What happened

The checked application graph is not valid JSON, has more or fewer than one app, or has an app ID that does not match.

## What to do

Run `relkit check` to regenerate the graph, then run `relkit deploy` again.

Reported by `@relkit/cli`, `relkit/deploy`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
