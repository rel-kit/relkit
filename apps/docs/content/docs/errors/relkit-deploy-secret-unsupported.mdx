**Graph contains a secret value.**

## What happened

The application graph contains a secret value, which must never be written into a deployment plan.

## What to do

Read the secret from an environment variable instead of writing it in code, or pass it with `relkit deploy --config-secret name=value`.

Reported by `@relkit/deploy`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
