**No application is running.**

## What happened

Code called `getRelkit()` outside a running RelKit application, for example from a script or a test that started no application.

## What to do

Call `getRelkit()` only in code the application runs, such as raw routes, middleware and `server.onStart`. In a script, create a handle with `createRelkit(config)` and close it when done.

Reported by `relkit/diagnostics`, `relkit/functions`.

See [all error codes](/docs/errors).
