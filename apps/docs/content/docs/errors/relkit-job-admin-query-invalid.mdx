**Job query is not valid.**

## What happened

A job query has a limit that is not a positive integer, or an unknown state filter.

## What to do

Use a positive whole number for the limit, and filter by `accepted`, `available`, `leased`, `delayed`, `completed` or `dead-lettered`.

Reported by `@relkit/diagnostics`, `@relkit/providers-local`.

See [all error codes](/docs/errors).
