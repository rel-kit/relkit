**Provider profile is not available.**

## What happened

Code uses a provider profile that does not exist or does not offer the needed feature, or several profiles exist and none is the default.

## What to do

Name an existing profile that offers the feature, or mark one profile as the default.

Reported by `@relkit/compiler`, `relkit/diagnostics`, `relkit/engine`.

See [all error codes](/docs/errors).
