**No build to start.**

## What happened

`relkit start` found no complete build in `.relkit/build`, because the project was never built or the last build did not finish.

## What to do

Run `relkit build` in the project and wait for it to succeed, then run `relkit start` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
