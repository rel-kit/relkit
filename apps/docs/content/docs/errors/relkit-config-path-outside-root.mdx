**Config path points outside the project.**

## What happened

A path in `relkit.config.ts` resolves to a location outside the project folder.

## What to do

Change the path so it stays inside the folder that contains `relkit.config.ts`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
