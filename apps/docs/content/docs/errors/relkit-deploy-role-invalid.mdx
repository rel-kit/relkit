**Deployment has more than one integration for a role.**

## What happened

The deployment found several integrations for a role that needs exactly one, or a binding lists the same access role twice.

## What to do

Keep one integration for the role named in the message in your app definition, then run `relkit deploy` again.

Reported by `relkit/deploy`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
