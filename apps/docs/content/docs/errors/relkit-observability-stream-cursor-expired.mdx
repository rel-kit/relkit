**Stream cursor is too old.**

## What happened

The stream cursor points to records that RelKit no longer keeps.

## What to do

Reconnect without a cursor to follow new records, and query past records separately if you need them.

Reported by `relkit/diagnostics`, `relkit/observability`.

See [all error codes](/docs/errors).
