**Source file does work when imported.**

## What happened

Importing a source file started a server, timer, child process or network call, wrote files, or printed output. RelKit loads files only to read definitions.

## What to do

Move that work into a handler or function that runs on request, so importing the file has no side effects.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
