**Stream was not read in time.**

## What happened

A stream started producing items, but nothing read from it within the idle limit, so it was closed.

## What to do

Start reading the stream as soon as you receive it, or raise the stream's idle limit.

Reported by `relkit/diagnostics`, `relkit/invocation`.

See [all error codes](/docs/errors).
