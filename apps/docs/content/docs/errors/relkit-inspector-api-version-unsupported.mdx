**Inspector API version not supported.**

## What happened

The Inspector asked for an API version that the running app does not support.

## What to do

Update all `@relkit/*` packages to the same version, then restart the app and refresh the Inspector.

Reported by `@relkit/diagnostics`, `@relkit/inspector-api`.

See [all error codes](/docs/errors).
