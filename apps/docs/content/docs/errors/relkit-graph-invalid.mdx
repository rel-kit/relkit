**Application graph is invalid.**

## What happened

The application graph file is not valid JSON or does not have the shape RelKit expects.

## What to do

Run `relkit check` to regenerate the graph, then run the command again.

Reported by `@relkit/cli`, `@relkit/diagnostics`, `@relkit/engine`.
