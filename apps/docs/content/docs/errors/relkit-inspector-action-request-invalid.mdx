**Inspector action request is invalid.**

## What happened

The Inspector sent an action request the app could not read.

## What to do

Refresh the Inspector and try again. If it keeps happening, make sure the Inspector and app use the same RelKit version.

Reported by `relkit/diagnostics`, `relkit/inspector-api`.

See [all error codes](/docs/errors).
