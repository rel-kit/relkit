**Raw route has no handler.**

## What happened

A raw route listed in the built manifest has no handler function at startup.

## What to do

Make sure the raw route exports a handler, then run `relkit build` again and restart the server.

Reported by `@relkit/diagnostics`, `@relkit/runtime-hono`.

See [all error codes](/docs/errors).
