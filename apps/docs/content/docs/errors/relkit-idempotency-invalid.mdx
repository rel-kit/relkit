**Idempotency settings are invalid.**

## What happened

The `idempotency` option is not an object, has no `key`, or has a `retentionMs` that is not a positive number.

## What to do

Set `idempotency` to an object with a non-empty `key` and a positive `retentionMs`.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
