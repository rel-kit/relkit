**Local bucket storage is not usable.**

## What happened

The local bucket provider found a problem with its storage, such as a missing or too broad root folder, a failed integrity check, or a provider that is already closed.

## What to do

Check the message for the cause. If local files were damaged, stop the app and delete the bucket folder under `.relkit/state`. This clears local objects.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
