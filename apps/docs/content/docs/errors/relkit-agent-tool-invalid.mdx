**Agent tool is invalid.**

## What happened

An agent's `tools` option is not an array, or one of its entries does not point to a tool defined in your app.

## What to do

Pass `tools` as an array of tools made with `defineTool`, and check that each one is exported from a file under `src/`.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
