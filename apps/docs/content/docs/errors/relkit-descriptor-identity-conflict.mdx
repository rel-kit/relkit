**Definition has conflicting IDs.**

## What happened

A function or other definition was registered with an ID that differs from the one it already has, or the ID is not a valid stable ID.

## What to do

Give each definition one stable ID and register it only once. Check for the same definition exported under two different IDs.

Reported by `@relkit/diagnostics`, `@relkit/invocation`.

See [all error codes](/docs/errors).
