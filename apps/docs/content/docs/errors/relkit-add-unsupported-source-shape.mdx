**Source file is too customized to edit.**

## What happened

`relkit add` needs to edit a file in your project, but the file no longer has a shape it can safely change, such as an app or database service it cannot find.

## What to do

Make the change by hand using the docs for what you are adding, or restore the file named in the message to its generated shape.

Reported by `create-relkit`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
