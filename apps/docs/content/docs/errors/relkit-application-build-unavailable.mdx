**No build for createRelkit.**

## What happened

`createRelkit(config)` found no build of the application in `.relkit/build`, or the build was made by a version without `createRelkit`.

## What to do

Run `relkit build` in the project root, then run the script again. Pass `{ root }` when the script runs from another directory.

Reported by `relkit/diagnostics`, `relkit/functions`.

See [all error codes](/docs/errors).
