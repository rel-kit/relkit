**Provider works only locally.**

## What happened

A provider binding is set up for local use only, but this build targets a real deployment.

## What to do

At the binding the error points at, give the adapter inside `docker(…)` its binding values, for example `docker(s3({ endpoint: env.url("S3_ENDPOINT"), … }))`, so release builds resolve them, or select an infrastructure source such as `aws(s3())` from `@relkit/aws`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
