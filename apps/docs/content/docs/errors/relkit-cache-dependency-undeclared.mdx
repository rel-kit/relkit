**Cache is not declared on this function.**

## What happened

A function used a cache that is not listed in its dependencies.

## What to do

Add the cache to the function's `dependencies`, for example `dependencies: { cache: { prices } }`.

Reported by `@relkit/cache`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
