**Vercel build refused the local provider for durable work.**

## What happened

`relkit build --target vercel` found jobs, schedules or events whose profile uses the local filesystem provider. A Vercel function keeps no files between invocations, so that work would be lost.

## What to do

Use the durable Postgres backend from `@relkit/postgres` (`relkit add jobs --provider postgres`, `relkit add events --provider postgres`) with a database the deployment can reach, and set `DATABASE_URL` on the Vercel project.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
