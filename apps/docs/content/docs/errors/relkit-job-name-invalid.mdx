**Job name is invalid or taken.**

## What happened

A job's name is not valid, or another job already uses it.

## What to do

Give the job a unique camelCase name that starts with a lower-case letter and uses only letters and numbers, such as `sendWelcomeEmail`.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
