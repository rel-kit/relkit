**Dynamic import cannot be checked.**

## What happened

A dynamic `import()` uses a path RelKit cannot read ahead of time, so it cannot confirm the import stays within domain boundaries.

## What to do

Use a string literal path in the `import()` call, or import through the other domain's public service.

Reported by `@relkit/compiler`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
