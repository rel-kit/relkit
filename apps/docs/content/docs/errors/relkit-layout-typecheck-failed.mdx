**Type check failed during layout migration.**

## What happened

The migrated copy of your project failed type checking, or type checking could not run, so no files were changed.

## What to do

Run `bun x tsc --noEmit` in the project and fix the errors, then run `relkit migrate layout` again.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
