**Provider integration is invalid.**

## What happened

An installed provider integration package registered itself in a way RelKit cannot use.

## What to do

Update or reinstall the integration package, then run `relkit build` again.

Reported by `@relkit/diagnostics`, `@relkit/engine`.

See [all error codes](/docs/errors).
