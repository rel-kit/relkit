**Event function is called directly.**

## What happened

Code calls an event-only function directly, or a route, job or tool targets it. Event functions run only when their event is published.

## What to do

Publish the event instead, or target a regular function made with `defineFunction`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
