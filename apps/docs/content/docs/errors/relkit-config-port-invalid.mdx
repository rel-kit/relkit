**Port is out of range.**

## What happened

A port in `relkit.config.ts` is not a whole number from 1 through 65535.

## What to do

Set the port named in the error to a whole number from 1 through 65535.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
