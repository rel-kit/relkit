**Agent model is not available.**

## What happened

The agent's model could not be resolved from the model registry or its configuration.

## What to do

Check the agent's `model` setting and that a model with that name is configured for this environment.

Reported by `@relkit/langchain`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
