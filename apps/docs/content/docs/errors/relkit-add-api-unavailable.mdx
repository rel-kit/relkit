**Scaffolding support could not be loaded.**

## What happened

`relkit add` could not load the `create-relkit` package it uses to add files to your project.

## What to do

Reinstall the CLI with `bun add -d @relkit/cli`, run `bun install`, then run `relkit add` again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
