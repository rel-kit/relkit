**Client contract version is not supported.**

## What happened

The server returned a client contract with a protocol or version this CLI does not support.

## What to do

Put the server and CLI on the same RelKit version, rebuild the server with `relkit build`, then run `relkit client pull` again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
