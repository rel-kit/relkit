**Better Auth is set up more than once.**

## What happened

The app registers more than one Better Auth service, or the Better Auth service is mounted on no route or on several routes.

## What to do

Keep one `defineBetterAuthService` and mount it on exactly one `ALL` catch-all route, then run `relkit check`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
