**Client contract is invalid.**

## What happened

The client contract downloaded from the server is not valid JSON, or its hash, procedures or errors are malformed.

## What to do

Make sure `<baseUrl>` points at a RelKit server, rebuild the server with `relkit build`, then run `relkit client pull` again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
