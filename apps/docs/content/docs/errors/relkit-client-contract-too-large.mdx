**Client contract is too large.**

## What happened

The client contract returned by the server is larger than the download limit `relkit client pull` accepts.

## What to do

Make sure `<baseUrl>` points at the RelKit server and not a proxy or other page, then try again.

Reported by `@relkit/cli`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
