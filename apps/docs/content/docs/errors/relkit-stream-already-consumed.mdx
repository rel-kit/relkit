**Stream was already read.**

## What happened

Code tried to read a stream a second time. A RelKit stream can be read only once.

## What to do

Read the stream once and keep the items you need, or call the function again to get a new stream.

Reported by `@relkit/diagnostics`, `@relkit/invocation`.

See [all error codes](/docs/errors).
