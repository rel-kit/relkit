**Route is outside the routes folder.**

## What happened

A route is defined in a file that is not a `route.ts` under `src/routes`.

## What to do

Move the route to `src/routes/**/route.ts`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
