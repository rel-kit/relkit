**Task progress update was cancelled.**

## What happened

A task tried to emit progress or a stream item after its run was cancelled or stopped.

## What to do

Check the task's abort signal before emitting, and stop work once the run is cancelled.

Reported by `@relkit/diagnostics`, `@relkit/jobs`.

See [all error codes](/docs/errors).
