**Event delivery cannot be retried.**

## What happened

Only dead-lettered event deliveries can be retried, and this delivery is in another state.

## What to do

Wait until the delivery is dead-lettered before retrying it, or let it finish on its own.

Reported by `relkit/diagnostics`, `relkit/providers-local`.

See [all error codes](/docs/errors).
