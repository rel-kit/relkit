**Added code would overwrite existing code.**

## What happened

`relkit add` found a file, service or `package.json` entry that already exists with different content, so it stopped instead of overwriting it.

## What to do

Choose a different name, or rename or remove the existing file or entry named in the message, then run `relkit add` again.

Reported by `create-relkit`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
