**Job cursor is invalid.**

## What happened

A page cursor sent to a jobs endpoint is malformed, too long, or was issued for a different request.

## What to do

Use the cursor exactly as returned by the previous page, with the same filters. Start again from the first page if unsure.

Reported by `relkit/diagnostics`, `relkit/jobs`, `relkit/runtime-hono`.

See [all error codes](/docs/errors).
