**App changed since the Inspector loaded.**

## What happened

The app was rebuilt or reloaded after the Inspector loaded, so the action targets an old build.

## What to do

Refresh the Inspector to load the current build, then try the action again.

Reported by `relkit/diagnostics`, `relkit/inspector-api`.

See [all error codes](/docs/errors).
