**Cleanup failed after the command finished.**

## What happened

The command finished, but RelKit could not release one or more resources afterwards, such as a temporary file or child process.

## What to do

Check for leftover processes or files named in the message and remove them. If this keeps happening, report this on the RelKit issue tracker with the full output.

Reported by `@relkit/cli`, `relkit/diagnostics`.
