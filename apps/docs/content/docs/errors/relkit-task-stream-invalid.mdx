**Stream item or name is not valid.**

## What happened

A task stream has an invalid name, or an emitted item failed the stream schema or cannot be turned into plain JSON.

## What to do

Check the message, give the stream a camelCase name such as `rowsProcessed`, and send items that match the stream schema.

Reported by `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
