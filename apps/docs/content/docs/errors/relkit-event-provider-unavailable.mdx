**Event provider cannot publish.**

## What happened

The configured event provider does not support publishing events.

## What to do

Configure an event provider that supports publishing for this profile in `relkit.config.ts`.

Reported by `relkit/diagnostics`, `relkit/events`.

See [all error codes](/docs/errors).
