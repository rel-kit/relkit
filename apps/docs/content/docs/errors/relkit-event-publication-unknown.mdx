**Published event is not defined.**

## What happened

A function's `publishes` option is not an array, or it lists an event that is not defined in your app.

## What to do

Make `publishes` an array of events defined with `defineEvent`.

Reported by `@relkit/compiler`, `relkit/diagnostics`.
