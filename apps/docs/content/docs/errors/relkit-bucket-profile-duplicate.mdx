**Bucket profile is used twice.**

## What happened

Two buckets claim the same bucket profile. Each profile can belong to only one bucket.

## What to do

Give one of the buckets a different profile, then run `relkit check`.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
