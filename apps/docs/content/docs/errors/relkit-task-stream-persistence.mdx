**Stream item was not saved.**

## What happened

The task needs stream items to be saved, but no store is configured or the store did not save the item.

## What to do

Configure a jobs provider that saves stream items, or check the provider's logs for the write error.

Reported by `@relkit/diagnostics`, `@relkit/jobs`.

See [all error codes](/docs/errors).
