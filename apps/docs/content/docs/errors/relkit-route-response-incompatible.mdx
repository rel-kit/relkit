**Route response does not match its function.**

## What happened

A route repeats a response, lists an error its function does not declare, or describes a response that does not match the function.

## What to do

Keep each response once and list only errors the target function declares in its `errors`.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
