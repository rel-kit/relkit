**Local state folder is not usable.**

## What happened

The folder RelKit uses for local provider state is empty, too broad, not a real folder, or damaged state could not be moved aside.

## What to do

Point the state root at a project folder you own, such as the default `.relkit/state`, and check that it is a normal writable folder.

Reported by `@relkit/diagnostics`, `@relkit/providers-local`.

See [all error codes](/docs/errors).
