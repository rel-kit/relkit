**Jobs request to the server failed.**

## What happened

The running server rejected the jobs request, returned an unexpected response, or has no job with that name.

## What to do

Make sure your app is running with `relkit dev` and the job name is correct, then try again.

Reported by `@relkit/cli`, `relkit/diagnostics`.
