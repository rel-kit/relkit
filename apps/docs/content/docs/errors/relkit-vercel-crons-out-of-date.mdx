**Vercel cron entries do not match the schedules.**

## What happened

`relkit build --target vercel` compared the `crons` in `vercel.json` with the ones the project's schedules need and found them different, or found no `vercel.json`. Vercel Cron only wakes the deployment for the entries in that file, so a schedule without its entry would never run.

## What to do

Run `relkit check`, then `relkit deploy init vercel --force` to rewrite `vercel.json` from the current schedules, review the change and commit it.

Reported by `@relkit/cli`, `relkit/diagnostics`.

See [all error codes](/docs/errors).
