**Definition is invalid.**

## What happened

An exported value is not a RelKit definition, or a definition has an option that is not allowed, such as an event version that is not a positive whole number.

## What to do

Fix the definition named in the error, or stop exporting values that are not RelKit definitions from that file.

Reported by `@relkit/compiler`, `@relkit/diagnostics`.

See [all error codes](/docs/errors).
