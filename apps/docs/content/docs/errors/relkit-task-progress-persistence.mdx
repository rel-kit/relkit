**Progress update was not saved.**

## What happened

The task needs progress to be saved, but no store is configured or the store did not save the update.

## What to do

Configure a jobs provider that saves progress, or check the provider's logs for the write error.

Reported by `relkit/diagnostics`, `relkit/jobs`.

See [all error codes](/docs/errors).
