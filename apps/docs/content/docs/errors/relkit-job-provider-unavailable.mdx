**Job provider cannot enqueue jobs.**

## What happened

The selected job provider does not implement enqueue.

## What to do

Configure a jobs provider that supports enqueue, or update the provider package to a version that does.

Reported by `@relkit/diagnostics`, `@relkit/jobs`.

See [all error codes](/docs/errors).
