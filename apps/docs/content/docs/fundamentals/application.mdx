---
title: Application, providers, and configuration
description: Define one provider topology and supply environment values from each pipeline.
---

`zsys.config.ts` exports one `defineConfig` descriptor. It contains application and runtime settings
plus top-level provider profiles. Database and authentication register through discovered descriptors,
not configuration.

```ts
import { defineConfig, defineEnv, env, external, redis, s3 } from "@zsys/app";

const values = defineEnv({
  BUCKET_ENDPOINT: env.url(),
  BUCKET_NAME: env.string(),
  BUCKET_REGION: env.string(),
  BUCKET_ACCESS_KEY_ID: env.secret().optional(),
  BUCKET_SECRET_ACCESS_KEY: env.secret().optional(),
  CACHE_URL: env.secret(),
});

export default defineConfig({
  env: values,
  buckets: {
    assets: external(
      s3({
        endpoint: values.BUCKET_ENDPOINT,
        bucketName: values.BUCKET_NAME,
        region: values.BUCKET_REGION,
        credentials: {
          accessKeyId: values.BUCKET_ACCESS_KEY_ID,
          secretAccessKey: values.BUCKET_SECRET_ACCESS_KEY,
        },
      }),
    ),
  },
  caches: { primary: external(redis({ url: values.CACHE_URL })) },
  defaults: { bucket: "assets", cache: "primary" },
  server: { port: 3000 },
  inspector: { port: 3210 },
});
```

`s3()` speaks the S3 protocol and works with AWS S3, Cloudflare R2, MinIO, and compatible
endpoints. `redis()` accepts `redis://` and `rediss://` URLs for Redis, Valkey, ElastiCache, and
Upstash's Redis protocol. `external(adapter)` connects without provisioning. `managed(adapter)`
allows the selected deployment target to provision and bind the resource.

Keep provider credentials as secret environment references. Literal secrets are rejected and values
never enter the graph, manifest, plan, inspector, or logs. `PORT` and `ZSYS_ENV` are framework-reserved;
pipelines select values without adding environment branches to application source. `requiredIn()`
remains available when a key is required only in selected runtime modes.

When only one profile exists its default is inferred. Multiple profiles need a singular default such
as `defaults.bucket` before unqualified use. If omitted, `id` comes from `package.json.name`.

Hosting is configured alongside the runtime settings:

```ts title="zsys.config.ts"
export default defineConfig({
  deployment: { target: "aws", adapter: "pulumi" },
});
```

Tests replace required bindings with deterministic in-memory fakes by default. Explicit integration
tests can opt into configured protocol adapters.
