Every route, job, event listener, service member, tool, and agent ultimately
invokes a function through the common engine.

`input` and `output` remain required because TypeScript types disappear at runtime. Their Standard
Schemas perform validation and provide graph metadata, OpenAPI shapes, generated client types, and
inspector forms. A target handler receives validated reusable input and a context containing only its
declared managed dependencies. HTTP request objects never enter a function.

IDs are optional for source-scoped functions, routes, services, tools, agents, errors, middleware, and
transforms. The compiler derives filesystem-safe IDs from source and export/member structure. Keep
explicit IDs when a refactor must preserve identity; application, event, job, bucket, and cache IDs
remain explicit because they address durable or external state.

Use `await target.invoke(input)` for nested function calls. It enters the active generation when one is
running and otherwise uses an isolated common kernel, preserving validation, service policy, limits,
trace, correlation, causation, deadline, cancellation, and observed child-call telemetry. Function
calls do not need a declared function dependency map; managed resources still do.

For HTTP, the route maps transport data into validated function input after matching middleware has
completed. Direct, HTTP, job, event, tool, and agent calls therefore use the same handler signature.

Use `onBefore(input, context)` to transform validated input and `onAfter(output, context)` to transform
a successful result. Each returned value is validated against the function schema; `onAfter` does not
run after a failure.

Services group member functions and shared policy without owning another handler:

```ts
const Orders = defineService({
  functions: { getOrder, createOrder },
  middleware: [ordersContext],
});

export const GET = defineRoute({ target: Orders.getOrder });
```

Use `getOrder.asTool({ description, sideEffect, approval })` for a function-derived tool. The tool
inherits the function schemas and errors, and `tool.invoke(input)` applies the same validation and
approval boundary.
