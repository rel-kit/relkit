title: Local development
description: Use one development command for reloads, diagnostics, OpenAPI, Scalar, and the inspector.
---

`bun run dev` runs the complete local feedback loop. It watches application source, checks a candidate
generation, starts it, verifies readiness, and only then makes it active.

## Development endpoints

| Surface          | Default URL                                      | Use it for                                     |
| ---------------- | ------------------------------------------------ | ---------------------------------------------- |
| Application      | `http://localhost:3000`                          | Calling authored routes                        |
| Inspector        | `http://localhost:3210`                          | Graph, diagnostics, logs, requests, and traces |
| OpenAPI JSON     | `http://localhost:3000/_relkit/v1/openapi.json`  | Tooling and client generation                  |
| Scalar reference | `http://localhost:3000/_relkit/v1/api-reference` | Interactive HTTP documentation                 |
| Readiness        | `http://localhost:3000/_relkit/v1/health/ready`  | Confirming the active generation can serve     |

## Follow a source change

<Steps>
  <Step>
    ### Keep the supervisor running

    ```sh title="Terminal — relkit-orders"
    bun run dev
    ```

    Wait for both URLs before editing.

  </Step>
  <Step>
    ### Make an invalid edit safely

    Temporarily misspell `defineRoute` in `src/routes/status/route.ts` and save. The candidate fails with a
    source-located diagnostic, while the last valid `/status` generation remains active.

  </Step>
  <Step>
    ### Repair and verify activation

    Restore `defineRoute`, save, and call:

    ```sh title="Terminal — relkit-orders"
    curl "http://localhost:3000/status"
    curl "http://localhost:3000/_relkit/v1/health/ready"
    ```

    The status route returns `{ "message": "Hello, world!" }`; readiness succeeds for the new generation.

  </Step>
</Steps>

## Configure ports and body limits

The generated configuration is executable source and contains both settings:

<include cwd lang="ts" meta='title="relkit.config.ts"'>
  ../../templates/default/v1/api/relkit.config.ts
</include>

Application port precedence is `--port`, `PORT`, `server.port`, then `3000`. Inspector precedence is
`--inspector-port`, `RELKIT_INSPECTOR_PORT`, `inspector.port`, then `3210`.

<Accordions type="multiple">
  <Accordion title="The backend port is already in use">
    Run `bun run relkit doctor --no-pulumi --port 3000 --inspector-port 3210`. Stop the reported
    process or choose a different port.
  </Accordion>
  <Accordion title="A save does not activate">
    Read the first candidate diagnostic and run `bun run check`. A schema, graph,
    provider-readiness, or evaluation error prevents activation by design.
  </Accordion>
  <Accordion title="Stopping development">
    Press `Ctrl-C` once in the supervisor terminal. RELKIT forwards shutdown to both child
    processes.
  </Accordion>
</Accordions>

Installed projects use the inspector bundled with `@relkit/cli`. `RELKIT_INSPECTOR_ROOT` is only for
framework contributors selecting another compatible inspector checkout.
