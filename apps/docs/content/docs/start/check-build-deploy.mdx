---
title: Check, test, build, and deploy
description: Use the smallest command that proves a change, then produce deterministic release artifacts.
---

```sh
bun run check
bun run typecheck
bun run test
bun run build
bun run start
```

`check` refreshes the typed event registry and validates descriptors, references, schemas, collisions,
and production requirements. `build` emits a graph, manifest, OpenAPI document, client, server, and
container files under `.relkit/build`. `start` refuses a stale or hash-mismatched build.

Inspect compatibility before deployment:

```sh
relkit graph print
relkit graph check
relkit graph diff before.json after.json
relkit deploy preview --stack staging
```

Deployment uses the checked graph through Pulumi. Review `preview` before `up`, isolate stacks by
environment, pass secrets through `--config-secret`, and never edit generated deployment files.
See [Deployment](/docs/operations/deployment) for the lifecycle and AWS mapping.
