Use the smallest layer that proves the behavior. Unit tests invoke one function; integration tests assemble
the checked application and call its in-process HTTP client. Both use the same schemas and common engine as
development.

<Tabs items={["Unit", "Integration"]}>
  <Tab value="Unit">
    Use `invokeFunction` for handler behavior, validation, declared errors, and explicitly supplied
    resource clients.
  </Tab>
  <Tab value="Integration">
    Use `createTestApplication` for routing, request mapping, middleware, responses, provider
    wiring, and OpenAPI behavior.
  </Tab>
</Tabs>
