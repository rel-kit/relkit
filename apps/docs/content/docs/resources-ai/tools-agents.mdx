A tool is a handler-free view of a function with a human description, side-effect classification,
approval policy, and timeout. Prefer `target.asTool({ ... })` when the tool belongs with the function;
`defineTool({ target, ... })` remains useful when metadata lives in a separate module. The target's
schemas and declared errors remain the validation contract, and `tool.invoke(input)` uses the common
engine. Use `approval: "always"` for sensitive or mutating work; missing approval fails closed.

Agents declare an input/output contract, optional serializable model selector, instructions, allowlisted
tools, and hard limits for steps, calls, and time. Omit `model` to use `defaultProvider` and
`defaultModel`; use a provider name for that provider's default model or `provider:model` for an exact
model. Only allowlisted tool IDs can execute. Approval decisions, tool invocations, model steps, and
errors are traced with redaction. Configure `modelProviders` on each environment with environment-backed
credentials; the live AI SDK v7 registry is created only after environment resolution.

```ts
production: awsProviders({
  region: env.AWS_REGION,
  modelProviders: {
    defaultProvider: "openai",
    defaultModel: "gpt-5-mini",
    openai: { apiKey: env.OPENAI_API_KEY },
    anthropic: { defaultModel: "claude-sonnet-4-5", apiKey: env.ANTHROPIC_API_KEY },
  },
});
```

Development and test runs can stay credential-free by using the repository's `ai/test`-backed harness;
they never need network model calls.
