## Expose the declared controls

Client-exposed agents require an agent-state profile. `useAgent` exposes only controls declared by the
agent: steer, follow-up, stop, and approval/denial. An agent with a reachable approval-requiring tool
must declare the approve capability.

## Observe without blocking execution

Persistent journal acceptance is separate from browser delivery. Slow observers detach with
`SLOW_CONSUMER` and recover from the journal; they never backpressure model or tool execution.
Browser projections contain validated public messages, parts, progress, tool data, and results—not
provider payloads, internal prompts, credentials, private context, or private reasoning.

Agent content streams and task progress/streams are separate contracts. Use a task job's run ID and generated
job client for background work; do not treat an agent graph state or realtime channel as a task run.
