Use `defineAgent` when a model needs to interpret a request and decide which tools to call. For a fixed sequence of steps, use [a function](/docs/fundamentals/functions).

Pass compatible LangChain models, tools, and middleware directly. RelKit validates the declared input,
output, limits, tool policies, and public client contract around the native execution. For exact options,
use the [RelKit reference](/docs/api/agents#defineagent).

See [Native runtime and DeepAgents](/docs/ai/native-runtime) for the supported package cohort, public
typing boundary, and deep-agent limitations. For explicit workflows and durable continuation, use
[LangGraph, persistence, and resume](/docs/ai/graphs-persistence).

## Install the native runtime

Generated agent projects already include the supported LangChain and LangGraph packages. Add them to an
existing application before declaring a native agent:

```sh
bun add langchain @langchain/langgraph
```

Model-provider packages are application dependencies. The generated sample uses LangChain's offline
`FakeToolCallingModel`, so its tests and first run need no account, network request, or paid service.

## Scaffold an agent

Add a native agent to an existing service with the installed CLI:

```sh
bun run relkit add agent Assistant --service hello
```

The scaffold uses the supported native packages and deterministic offline model. Replace that model in
server code when you are ready to configure a production provider.

## Scaffold a reusable prompt

Create a prompt before referencing it from an agent:

```sh
bun run relkit add prompt "Greeting Policy" --service hello \
  --text "Answer greeting questions." --text "Keep answers brief."
```

The prompt is saved as `src/hello/prompts/greeting-policy.prompt.ts`; repeated non-empty `--text`
values preserve separate prompt segments. In headless execution at least one `--text` is required.
Prompts are internal descriptors, not public service members. Pass the prompt descriptor as the
agent's `instructions` when you need reusable policy text.

## Define the task

This agent answers greeting questions using a single tool. Create it after [defining the lookup tool](/docs/ai/function-tools).

<include cwd lang="ts" meta='title="src/hello/agents/assistant.agent.ts"'>

</include>

`input` describes what your app sends; `output` describes the answer your app expects. RelKit validates both. Output validation checks the shape, not whether the model's answer is factually correct.

Write `instructions` that explain when to use each tool and how to answer. The agent can call only tools in its `tools` array. Start with the smallest set needed for the task.

## Set limits

All three `limits` are required positive integers:

| Option         | What it limits                  |
| -------------- | ------------------------------- |
| `maxSteps`     | Model steps in a run.           |
| `maxToolCalls` | Total tool calls in a run.      |
| `timeoutMs`    | Total run time in milliseconds. |

If a run exceeds a limit, it fails rather than continuing indefinitely. Set limits that fit your task and handle failures in the calling application.

## Choose a model

`model` accepts a compatible native LangChain model instance or a lazy application model. Install and
configure the provider package in server code; never put credentials, live instances, or provider
payloads in browser contracts. Subagents inherit the parent model unless they declare an override.

## Run the typed client

Expose the agent through `client`, then select it with `useAgent`. Run, observe, stop, and resume calls
all require the caller's stable business thread ID:

The generated selector narrows initial input, final output, selected middleware state, tools, custom
events, waiting replies, and controls. A resume uses the same thread with `{ resume: true }`; it does not
start a replacement run.

Keep authorization in your application functions. Model instructions are not a replacement for checking whether the current user may read or change data.

## Streaming

The client-exposed agent has a durable thread journal: `useAgent` restores its authorized snapshot and
observes text parts, tool calls, progress, approvals, selected state, nested execution, and terminal
output incrementally. Mounting the hook never creates a thread or starts a run. See
[Agent streaming](/docs/ai/streaming) and [Threads and recovery](/docs/ai/threads-recovery).
