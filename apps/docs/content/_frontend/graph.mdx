`defineGraph` generates an agent client too. The initial `run` receives `{ orderId }`; the review
node's `resume: z.boolean()` makes the continuation accept a boolean. Resume the same thread with
`{ resume: true }`, and show the final `output.result`. Do not send a replacement initial run to
answer an interrupt or replay an uncertain submission.
