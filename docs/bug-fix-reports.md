# Bug-fix reports

Bug-fix and UI bug-fix reports are no longer committed. New defects are tracked as
[GitHub issues](https://github.com/rel-kit/relkit/issues), with reproduction notes and evidence in
the issue and the fixing pull request. `bun run check` fails when a file is added under
`bug-fix-reports/` or `bug-fix-ui-reports/`.

The reports below were committed before that rule. None of them had a GitHub issue; each link opens
the report as it was at commit `a93fed1e8`.
