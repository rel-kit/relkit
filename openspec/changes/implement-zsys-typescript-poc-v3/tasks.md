Keep work visible on `fix/implement-zsys-typescript-poc-v3`, leave it uncommitted unless the user explicitly authorizes Git publication actions, and use no worktree or hidden branch. Until Phase 0 installs the minimal project-local agent profiles, record delegation as unavailable rather than inventing a profile.

The final checkbox of every phase is a fresh read-only gate unit. It reruns the corresponding review-gate reproduction commands against a committed candidate from a clean worktree, records base/candidate commit IDs and final `git status --short`, checks every rejection condition, and blocks the next phase until the candidate and evidence are merged. Missing commit/PR authority or an unmerged prerequisite is a recorded blocker, not permission to weaken the gate. Any task that edits another owner's surface reruns both owners' affected checks.

Every unit follows `AGENTS.md`: implementation files stay at or below 200 lines; public APIs and non-obvious invariants receive useful JSDoc/comments; the nearest README/spec and repository guidance stay accurate; and affected Prettier, ESLint, boundary, type, test, build, and configured structural checks run before handoff.
